Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། ཁོང་ཁྲོ་བྱ་བར་མི་རིགས་པ་དང༌། བཟོད་པ་བསྟེན་པར་རིགས་པའོ། །དང་པོ་ལ་བཞི། དགོས་པ་མེད་ཅིང་ཉེས་དམིགས་ཆེ་བས་ཁོང་ཁྲོ་བར་མི་རིགས་པ། ཕྱིས་ཀྱི་སྡུག་བསྔལ་མི་འདོད་པ་དང་གནོད་ལན་བྱེད་པ་གཉིས་འགལ་བར་བསྟན་པ། སྔར་ཡུན་རིང་བསགས་པའི་དགེ་བ་འཇོམས་པས་ཁོང་ཁྲོ་བར་མི་རིགས་པ། མི་བཟོད་པའི་སྐྱོན་མང་པོ་བསམས་ནས་ཁོང་ཁྲོ་དགག་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། དཀྱུས་ཀྱི་དོན་དང༌། ཞར་བྱུང་གི་དོན་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། བཟོད་པའི་ཡོན་ཏན་མང་པོ་བསམ་པ་དང༌། དོན་བསྡུས་ཏེ་བཟོད་པ་བསྟེན་པར་གདམས་པའོ། །
Enumeration Block 4:
བཞི་པ་ས་བཞི་པ་འོད་འཕྲོ་བ་བཤད་པ་ལ་གསུམ། ས་འདིར་བརྩོན་འགྲུས་ལྷག་པར་བསྟན་པ། སའི་ངེས་པའི་ཚིག་བསྟན་པ། སྤངས་པའི་ཁྱད་པར་བསྟན་པའོ། །
Enumeration Block 5:
ལྔ་པ་ས་ལྔ་པ་སྦྱང་བཀའ་བ་བཤད་པ་ལ་གཉིས། ས་ལྔ་པའི་ངེས་པའི་ཚིག་བཤད་པ། བསམ་གཏན་ལྷག་ཅིང་བདེན་པ་ལ་མཁས་པར་བསྟན་པའོ། །
Enumeration Block 6:
གཉིས་པ་ས་དྲུག་པ་མངོན་དུ་གྱུར་པ་བཤད་པ་ལ་བཞི། སའི་ངེས་ཚིག་དང་ཤེར་ཕྱིན་ལྷག་པར་བསྟན་པ། ཤེས་རབ་ཀྱི་ཕར་ཕྱིན་གྱི་བསྔགས་པ། ཟབ་མོ་རྟེན་འབྱུང་གཟིགས་པའི་དེ་ཁོ་ན་ཉིད་བཤད་པ། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 7:
གསུམ་པ་ལ་ལྔ། ཟབ་མོའི་དོན་བཤད་པར་དམ་བཅའ་བ། ཟབ་མོའི་དོན་བཤད་པའི་སྣོད་ངོས་བཟུང་བ། དེ་ལ་བཤད་ན་ཡོན་ཏན་འབྱུང་ཚུལ། སྣོད་ལྡན་གྱི་གང་ཟག་ལ་ཉན་པར་བསྐུལ་བ། རྟེན་འབྱུང་གི་དེ་ཉིད་ཇི་ལྟར་བཤད་པའི་ཚུལ་ལོ། །
