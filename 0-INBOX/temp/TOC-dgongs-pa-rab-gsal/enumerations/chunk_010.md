Enumeration Block 1:
གཉིས་པ་སེམས་ཙམ་པའི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་ལ་གསུམ། ཕྱི་རོལ་མེད་པའི་ཤེས་པ་རང་བཞིན་གྱིས་གྲུབ་པ་དགག །གཞན་དབང་རང་བཞིན་གྱིས་གྲུབ་པའི་སྒྲུབ་བྱེད་ཚད་མ་དགག །སེམས་ཙམ་དུ་གསུངས་པའི་ཙམ་གྱི་སྒྲས་ཕྱི་དོན་འགོག་པ་མིན་པར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། གཞན་ལུགས་བརྗོད་པ་དང༌། ལུགས་དེ་དགག་པའོ།
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། དགག་པ་རྒྱས་པར་བརྗོད་པ་དང༌། དེ་ལྟར་བཀག་པའི་མཇུག་བསྡུ་བའོ། ། དང་པོ་ལ་གསུམ། ཕྱི་རོལ་མེད་པའི་ཤེས་པ་རང་བཞིན་གྱིས་གྲུབ་པའི་དཔེ་དག །བག་ཆགས་ཀྱི་ནུས་པ་ལས་དོན་གྱིས་སྟོང་པའི་ཤེས་པ་སྐྱེ་བའི་དོན་དགག །དེ་ལྟར་བཀག་པ་དང་མི་སྡུག་པ་སྒོམ་པ་གཉིས་མི་འགལ་བར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། རྨི་ལམ་གྱི་དཔེ་དགག་པ། སྐྲ་ཤད་མཐོང་བའི་དཔེ་དགག་པའོ། །དང་པོ་ལ་གསུམ། རྨི་ལམ་གྱི་དཔེས་ཤེས་པ་རང་བཞིན་གྱིས་ཡོད་པ་མི་འགྲུབ་པ། རྨི་ལམ་གྱི་དཔེས་སད་དུས་སུ་ཕྱི་རོལ་མེད་པ་མི་འགྲུབ་པ། རྨི་ལམ་གྱི་དཔེས་དངོས་པོ་ཐམས་ཅད་རྫུན་པར་འགྲུབ་པའོ།
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། བག་ཆགས་སྨིན་མ་སྨིན་ཉིད་ལས་དོན་སྣང་གི་རྣམ་ཤེས་སྐྱེ་བ་དང་མི་སྐྱེ་བ་དགག་པ། སླར་ཡང་ཕྱི་རོལ་མེད་པར་རྣམ་ཤེས་ཡོད་ཚུལ་བརྗོད་པ་དགག་པ། སེམས་ཙམ་གྱི་ལུགས་བཀག་པ་ལ་ལུང་གི་གནོད་པ་མེད་པར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། གཞན་ལུགས་བརྗོད་པ་དང༌། ལུགས་དེ་དགག་པའོ།
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། ད་ལྟར་བ་ལ་ནུས་པ་རང་བཞིན་གྱིས་གྲུབ་པ་དགག །མ་འོངས་པའི་ནུས་པ་རང་བཞིན་གྱིས་གྲུབ་པ་དགག །འདས་པ་ལ་ནུས་པ་རང་བཞིན་གྱིས་གྲུབ་པ་དགག་པའོ།
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། གཞན་གྱི་ལུགས་བརྗོད་པ་དང༌། ལུགས་དེ་དགག་པའོ།
Enumeration Block 6:
གཉིས་པ་ལ་བཞི། གཞན་དབང་གི་སྒྲུབ་བྱེད་རང་རིག་དགག་པ། སེམས་ཙམ་པའི་ལུགས་བདེན་པ་གཉིས་ཆར་ལས་ཉམས་པར་བསྟན་པ། དེས་ན་ཀླུ་སྒྲུབ་ཀྱི་ལུགས་ཁོ་ནའི་རྗེས་སུ་འབྲང་བར་རིགས་པ། གཞན་དབང་དང་འཇིག་རྟེན་པའི་ཐ་སྙད་འགོག་པ་གཉིས་མི་མཚུངས་པར་བསྟན་པའོ། དང་པོ་ལ་བཞི། གཞན་དབང་གི་སྒྲུབ་བྱེད་དྲིས་ནས་དེ་མི་འཐད་པར་བསྟན་པ། དེ་འཐད་པའི་གཞན་གྱི་ལན་དགག་པ། རིགས་པ་གཞན་གྱིས་ཀྱང་རང་རིག་མི་འཐད་པར་བསྟན་པ། གཞན་དབང་རང་བཞིན་གྱིས་གྲུབ་པ་མོ་གཤམ་གྱི་བུ་དང་མཚུངས་པར་བསྟན་པའོ།
