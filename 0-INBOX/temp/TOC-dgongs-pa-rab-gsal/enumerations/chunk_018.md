Enumeration Block 1:
གསུམ་པ་ལ་གསུམ། བུམ་སྣམ་སོགས་ཀྱི་དངོས་པོ་ལ་བསྒྲེ་བ། རྒྱུ་དང་འབྲས་བུའི་དངོས་པོ་ལ་བསྒྲེ་བ། དེ་ལ་གཞན་གྱི་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། རྒྱུ་འབྲས་རང་བཞིན་གྱིས་གྲུབ་པ་འགོག་པ་ལ་སྐྱོན་མཚུངས་པའི་རྩོད་པ། རང་ལ་སྐྱོན་མི་མཚུངས་པའི་ལན་བསྟན་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི། རང་གི་ཕྱོགས་ལ་སུན་འབྱིན་དང་སྒྲུབ་པ་འཐད་ཚུལ། གཞན་གྱི་ཐལ་བ་མི་མཚུངས་པའི་རྒྱུ་མཚན་གསལ་བར་བཤད་པ། རང་བཞིན་མེད་པ་སྒྲུབ་ནུས་པ་བཞིན་དུ་གཞན་གྱིས་བཟློག་སྟེ་བསྒྲུབ་མི་ནུས་པ། འདིར་མ་བཤད་པའི་སུན་འབྱིན་ལྷག་མ་ཤེས་པར་བྱེད་ཚུལ་ལོ། །
Enumeration Block 4:
དང་པོ་ལ་གཉིས། ཐ་སྙད་དུ་གཞན་ཕྱོགས་སུན་འབྱིན་པ་ཁས་ལེན་ཚུལ་དང༌། རང་གི་ཕྱོགས་སྒྲུབ་པ་ཁས་ལེན་ཚུལ་ལོ། །
Enumeration Block 5:
གསུམ་པ་ལ་གཉིས། སྟོང་པ་ཉིད་ཀྱི་དབྱེ་བ་མདོར་བསྟན་པ། ཕྱེ་བ་སོ་སོའི་དོན་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། སྟོང་ཉིད་བཅུ་དྲུག་ཏུ་ཕྱེ་བ་རྒྱས་པར་བཤད་པ་དང༌། སྟོང་ཉིད་བཞིར་ཕྱེ་བ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་བཞི། ནང་སྟོང་པ་ཉིད་ལ་སོགས་པ་བཞི་བཤད་པ་དང༌། ཆེན་པོ་སྟོང་པ་ཉིད་ལ་སོགས་པ་བཞི་བཤད་པ་དང༌། མཐའ་ལས་འདས་པ་སྟོང་པ་ཉིད་ལ་སོགས་པ་བཞི་བཤད་པ་དང༌། ཆོས་ཐམས་ཅད་སྟོང་པ་ཉིད་ལ་སོགས་པ་བཞི་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ནང་སྟོང་པ་ཉིད་བཤད་པ་དང༌། སྟོང་ཉིད་ལྷག་མ་གསུམ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། ཞར་ལ་རང་བཞིན་ཁས་ལེན་ཚུལ་བསྟན་པའོ། །
