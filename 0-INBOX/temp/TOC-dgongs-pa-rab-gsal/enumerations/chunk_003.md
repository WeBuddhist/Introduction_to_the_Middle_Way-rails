Enumeration Block 1:
གསུམ་པ་ལ་བཞི། ས་དང་པོ་ལ་གནས་པའི་སྦྱིན་པ་བཤད་པ། རྟེན་དམན་པ་རྣམས་ཀྱི་སྦྱིན་པ་བཤད་པ། བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སྦྱིན་པ་བཤད་པ། སྦྱིན་པའི་ཕར་ཕྱིན་གྱི་དབྱེ་བ་བསྟན་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སྦྱིན་པས་འཁོར་བའི་བདེ་བ་འཐོབ་པ་དང༌། སྦྱིན་པས་མྱང་འདས་ཀྱི་བདེ་བ་འཐོབ་པར་བསྟན་པའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་བཞི། བྱང་སེམས་ཀྱི་སྦྱིན་པའི་ཕན་ཡོན་ཐུན་མོང་མ་ཡིན་པ་བསྟན་པ། རྟེན་གཉིས་ཀ་ལ་སྦྱིན་པའི་གཏམ་གཙོ་བོར་བསྟན་པ། བྱང་སེམས་ཀྱིས་སྦྱིན་པའི་ཚེ་དགའ་བ་ཇི་འདྲ་བ་འཐོབ་པ་བསྟན་པ། བྱང་སེམས་ཀྱིས་ལུས་སྦྱིན་པ་ལ་སྡུག་བསྔལ་ཡོད་མེད་བསྟན་པའོ། །
Enumeration Block 4:
གཉིས་པ་ས་གཉིས་པ་དྲི་མ་མེད་པ་བཤད་པ་ལ་ལྔ། ས་འདིར་ཚུལ་ཁྲིམས་ཡོངས་སུ་དག་པར་བསྟན་པ་དང༌། ཚུལ་ཁྲིམས་ཀྱི་བསྔགས་པ་བསྟན་པ་དང༌། ཚུལ་ཁྲིམས་ཀྱི་མི་མཐུན་ཕྱོགས་དང་མ་འདྲེས་པའི་དཔེ་བསྟན་པ་དང༌། ཚུལ་ཁྲིམས་ཀྱི་ཕར་ཕྱིན་གྱི་དབྱེ་བ་བསྟན་པ་དང༌། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུ་བའོ། །དང་པོ་ལ་བཞི། ས་འདིར་ཚུལ་ཁྲིམས་ཕུན་སུམ་ཚོགས་པར་བསྟན་པ། དེ་ལ་བརྟེན་ནས་ཡོན་ཏན་ཡོངས་སུ་དག་པར་བསྟན་པ། ས་དང་པོ་ལས་ཚུལ་ཁྲིམས་ལྷག་པར་བསྟན་པ། ཚུལ་ཁྲིམས་ཡོངས་སུ་དག་པའི་རྒྱུ་གཞན་བསྟན་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལྔ། སྦྱིན་འབྲས་བདེ་འགྲོར་སྤྱོད་པ་ཚུལ་ཁྲིམས་ལ་རག་ལས་པ། སྦྱིན་འབྲས་ལ་སྐྱེ་བ་བརྒྱུད་མར་སྤྱོད་པ་ཚུལ་ཁྲིམས་ལ་རག་ལས་པ། ཚུལ་ཁྲིམས་དང་བྲལ་ན་ངན་འགྲོ་ལས་ཐར་པ་ཤིན་ཏུ་དཀའ་བར་བསྟན་པ། སྦྱིན་པའི་གཏམ་གྱི་རྗེས་སུ་ཚུལ་ཁྲིམས་ཀྱི་གཏམ་མཛད་པའི་རྒྱུ་མཚན། མངོན་མཐོ་དང་ངེས་ལེགས་གཉིས་ཀའི་རྒྱུར་ཚུལ་ཁྲིམས་བསྔགས་པའོ། །
Enumeration Block 6:
གསུམ་པ་ས་གསུམ་པ་འོད་བྱེད་པ་བཤད་པ་ལ་བཞི། ཁྱད་པར་གྱི་གཞི་སའི་ངེས་ཚིག །ཁྱད་པར་གྱི་ཆོས་སའི་ཡོན་ཏན། ཕར་ཕྱིན་དང་པོ་གསུམ་གྱི་ཁྱད་པར་གྱི་ཆོས། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་བཞི། ས་འདིར་བཟོད་པ་ལྷག་པར་བསྟན་པ། བཟོད་པ་གཞན་ཇི་ལྟར་བསྟེན་པའི་ཚུལ། བཟོད་པའི་ཕར་ཕྱིན་གྱི་དབྱེ་བ། ས་འདིར་འབྱུང་བའི་དག་པའི་ཡོན་ཏན་གཞན་བསྟན་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། ཁོང་ཁྲོ་བྱ་བར་མི་རིགས་པ་དང༌། བཟོད་པ་བསྟེན་པར་རིགས་པའོ། །དང་པོ་ལ་བཞི། དགོས་པ་མེད་ཅིང་ཉེས་དམིགས་ཆེ་བས་ཁོང་ཁྲོ་བར་མི་རིགས་པ། ཕྱིས་ཀྱི་སྡུག་བསྔལ་མི་འདོད་པ་དང་གནོད་ལན་བྱེད་པ་གཉིས་འགལ་བར་བསྟན་པ། སྔར་ཡུན་རིང་བསགས་པའི་དགེ་བ་འཇོམས་པས་ཁོང་ཁྲོ་བར་མི་རིགས་པ། མི་བཟོད་པའི་སྐྱོན་མང་པོ་བསམས་ནས་ཁོང་ཁྲོ་དགག་པའོ། །
Enumeration Block 9:
གསུམ་པ་ལ་གཉིས། དཀྱུས་ཀྱི་དོན་དང༌། ཞར་བྱུང་གི་དོན་བཤད་པའོ། །
