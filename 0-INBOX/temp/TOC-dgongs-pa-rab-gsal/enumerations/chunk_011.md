Enumeration Block 1:
གཉིས་པ་ལ་བཞི། གཞན་དབང་གི་སྒྲུབ་བྱེད་རང་རིག་དགག་པ། སེམས་ཙམ་པའི་ལུགས་བདེན་པ་གཉིས་ཆར་ལས་ཉམས་པར་བསྟན་པ། དེས་ན་ཀླུ་སྒྲུབ་ཀྱི་ལུགས་ཁོ་ནའི་རྗེས་སུ་འབྲང་བར་རིགས་པ། གཞན་དབང་དང་འཇིག་རྟེན་པའི་ཐ་སྙད་འགོག་པ་གཉིས་མི་མཚུངས་པར་བསྟན་པའོ། །དང་པོ་ལ་བཞི། གཞན་དབང་གི་སྒྲུབ་བྱེད་དྲིས་ནས་དེ་མི་འཐད་པར་བསྟན་པ། དེ་འཐད་པའི་གཞན་གྱི་ལན་དགག་པ། རིགས་པ་གཞན་གྱིས་ཀྱང་རང་རིག་མི་འཐད་པར་བསྟན་པ། གཞན་དབང་རང་བཞིན་གྱིས་གྲུབ་པ་མོ་གཤམ་གྱི་བུ་དང་མཚུངས་པར་བསྟན་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། གཞན་གྱི་ལུགས་བརྗོད་པ་དང༌། ལུགས་དེ་དགག་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། གཞན་ལུགས་དགག་པ་དངོས། རང་ལུགས་ལ་རང་རིག་མེད་ཀྱང་དྲན་པ་སྐྱེ་བའི་ཚུལ། དེ་ལྟར་བཀག་པ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། གཞུང་འདི་ཉིད་ནས་བཤད་པའི་ལུགས་དང༌། གཞུང་གཞན་ནས་བཤད་པའི་ལུགས་སོ། །
Enumeration Block 5:
གསུམ་པ་ལ་གཉིས། མངོན་སུམ་གྱི་ཚད་མ་གཞན་དང་རྗེས་དཔག་ལ་རྩོད་པ་སྤང་བ་དང༌། ཡིད་ཤེས་གཞན་གྱི་རྩོད་སྤང་ངོ༌། །
