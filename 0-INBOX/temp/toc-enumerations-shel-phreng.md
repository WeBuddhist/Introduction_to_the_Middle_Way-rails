Enumeration Block 1:
དབུ་མ་ལ་འཇུག་པ་འདི་འཆད་པ་ལ། མཚན་གྱི་དོན། འགྱུར་གྱི་ཕྱག ། གཞུང་གི་དོན། མཇུག་གི་དོན་དང་བཞི་ལས།
Enumeration Block 2:
གསུམ་པ་ལ། བསྟན་བཅོས་རྩོམ་པ་ལ་འཇུག་པའི་ཡན་ལག་མཆོད་པར་བརྗོད་པ། བརྩམ་བྱ་བསྟན་བཅོས་ཀྱི་ལུས་དངོས། བརྩམ་པ་མཐར་ཕྱིན་པའི་བྱ་བའོ། །དང་པོ་ལ། བྱང་སེམས་ཀྱི་རྒྱུ་གསུམ་སྤྱིར་བསྟན་པ་དང་། དེ་ལས་བྱེ་བྲག་ཏུ་སྙིང་རྗེ་ལ་བསྟོད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། སྙིང་རྗེ་ཆེན་པོ་ལ་སོ་སོར་མ་ཕྱེ་བར་བསྟོད་པ་དང་། ཕྱེ་སྟེ་ཕྱག་འཚལ་བ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། སེམས་ཅན་ལ་དམིགས་པའི་སྙིང་རྗེ་ལ་བསྟོད་པ་དང་། ཆོས་དང་དམིགས་པ་མེད་པའི་སྙིང་རྗེ་ལ་བསྟོད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་བརྩམ་བྱ་བསྟན་བཅོས་ཀྱི་ལུས་དངོས་ལ། གནས་སྐབས་ཀྱི་ས་བཤད་པ་དང་། མཐར་ཐུག་གི་ས་བཤད་པ་གཉིས། དང་པོ་ལ། ས་བཅུ་སོ་སོར་བཤད་པ་དང་། ས་ཡི་ཡོན་ཏན་བཤད་པ་གཉིས། དང་པོ་ལ་རབ་དགའ་སོགས་ལྔ་བཤད་པ་དང་། ས་དྲུག་པ་མངོན་དུ་གྱུར་པ་བཤད་པ། རིང་དུ་སོང་བ་སོགས་བཞི་བཤད་པའོ། །
Enumeration Block 6:
དང་པོ་ལ་ས་དང་པོ་རབ་ཏུ་དགའ་བ་བཤད་པ། གཉིས་པ་དྲི་མ་མེད་པ། གསུམ་པ་འོད་བྱེད་པ། བཞི་པ་འོད་འཕྲོ་བ། ལྔ་པ་སྦྱང་དཀའ་བ་བཤད་པ་དང་ལྔ། དང་པོ་ལ། ས་དང་པོ་དངོས་བཤད་པ་དང་། ལེའུའི་སྐབས་བསྡུ་བ་གཉིས། དང་པོ་ལ། ཁྱད་གཞི་ས་ཡི་ངོ་བོ་མདོར་བསྟན། ཁྱད་ཆོས་ས་ཡི་ཡོན་ཏན་རྒྱས་པར་བཤད་པ། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུ་བ་དང་གསུམ།
Enumeration Block 7:
གཉིས་པ་ལ། རང་གི་རྒྱུད་མཛེས་པར་བྱེད་པའི་ཡོན་ཏན། གཞན་གྱི་རྒྱུད་ཟིལ་གྱིས་གནོན་པའི་ཡོན་ཏན། ས་དང་པོར་ལྷག་པའི་ཡོན་ཏན་བསྟན་པ་དང་གསུམ། དང་པོ་ལ་དོན་ལྡན་གྱི་མཚན་ཐོབ་པའི་ཡོན་ཏན། རིགས་སུ་སྐྱེ་བ་སོགས་བླང་བྱའི་ཁྱད་པར་ཐོབ་པའི་ཡོན་ཏན། ངན་སོང་སོགས་སྦྱང་བྱ་འགགས་པའི་ཡོན་ཏན་གསུམ།
Enumeration Block 8:
གཉིས་པ་ལ། རིགས་ཀྱི་ཡོན་ཏན། སྤངས་པའི་ཡོན་ཏན། རྟོགས་པའི་ཡོན་ཏན། ནུས་པའི་ཡོན་ཏན། གོང་དུ་འཕེལ་བའི་ཡོན་ཏན་ལྔ།
Enumeration Block 9:
གསུམ་པ་ལ་དངོས་དང་། དེ་དཔེས་བཤད་པ་གཉིས།
Enumeration Block 10:
གཉིས་པ་གཞན་ཟིལ་གྱིས་གནོན་ཚུལ་ལ། དངོས་དང་འཕྲོས་དོན་གཉིས།
Enumeration Block 11:
གསུམ་པ་ས་དང་པོར་ལྷག་པའི་ཡོན་ཏན་ལ། ས་འདིར་སྦྱིན་པའི་ཕར་ཕྱིན་ལྷག་ཚུལ། སྦྱིན་པའི་བསྔགས་པ། སྦྱིན་པའི་དབྱེ་བ་གསུམ།
Enumeration Block 12:
གཉིས་པ་ལ། སྦྱིན་པའི་བསྔགས་པ་དངོས་དང་། བསྔགས་པ་དེ་ལྡན་གྱི་སྦྱིན་པ་ལ་བྱང་སེམས་རྣམས་གུས་པའི་ཚུལ་གཉིས། དང་པོ་ལ། རྟེན་དམན་པའི་སྦྱིན་པ་ལ་བསྔགས་པ། བྱང་སེམས་རྣམས་ཀྱི་སྦྱིན་པ་ལ་བསྔགས་པ། དེ་ལྟར་བསྔགས་པའི་མཇུག་བསྡུ་བ་གསུམ། དང་པོ་ལ། རྟེན་དམན་པ་ལ་སྦྱིན་པ་དགོས་ཚུལ་དང་། སྦྱིན་པ་བྱིན་པའི་ཕན་ཡོན་གཉིས།
Enumeration Block 13:
གཉིས་པ་ལ་སྦྱིན་པས་འཁོར་བའི་བདེ་བ་ཐོབ་ཚུལ་དང་། སྦྱིན་པས་མྱང་འདས་ཀྱི་བདེ་བ་ཐོབ་ཚུལ་གཉིས།
Enumeration Block 14:
གཉིས་པ་བསྔགས་པ་དེ་ལྡན་གྱི་སྦྱིན་པ་ལ་བྱང་སེམས་རྣམས་གུས་ཚུལ་ལ། སྦྱིན་པ་ལ་ཅི་ཙམ་གུས་པའི་ཚུལ་དང་། དེ་ལྟར་གུས་ནས་སྦྱིན་པ་གཏོང་ཚུལ་གཉིས།
Enumeration Block 15:
གཉིས་པ་དྲི་མ་མེད་པ་བཤད་པ་ལ། དངོས་དང་། ལེའུའི་སྐབས་བསྡུ་བ་གཉིས། དང་པོ་ལ། ཁྱད་གཞི་སའི་ངེས་ཚིགས་དེའི་ཁྱད་པར་གྱི་ཆོས། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུ་བ་གསུམ།
Enumeration Block 16:
གཉིས་པ་ལ། ས་འདིར་ཚུལ་ཁྲིམས་ཀྱི་ཕར་ཕྱིན་ལྷག་ཅིང་དག་པར་བསྟན་པ། ཚུལ་ཁྲིམས་ཀྱི་བསྔགས་པ། ཚུལ་ཁྲིམས་ཕར་ཕྱིན་གྱི་དབྱེ་བ་གསུམ། དང་པོ་ལ་དངོས་དང་། ཚུལ་ཁྲིམས་དག་ཚུལ་བཤད་པ་གཉིས།
Enumeration Block 17:
གཉིས་པ་ཚུལ་ཁྲིམས་ཀྱི་བསྔགས་པ་ལ། བསྔགས་པ་དངོས་དང་། བསྔགས་པ་དེ་ལྡན་གྱི་ཚུལ་ཁྲིམས་ལ་བྱང་སེམས་རྣམས་གནས་ཚུལ་གཉིས། དང་པོ་ལ་རྟེན་དམན་པར་ཡང་ཚུལ་ཁྲིམས་དགོས་ཚུལ་དང་། ཡོན་ཏན་ཐམས་ཅད་ཀྱི་རྟེན་དུ་འགྱུར་ཚུལ་གཉིས། དང་པོ་ལ། ཚུལ་ཁྲིམས་དང་བྲལ་བའི་ཉེས་དམིགས་དང་། ལྡན་པའི་ཕན་ཡོན་གཉིས། དང་པོ་ལ། ཚུལ་ཁྲིམས་དང་བྲལ་ན་བདེ་འགྲོ་མི་ཐོབ་པའི་སྐྱོན་དང་། བདེ་འབྲས་ལན་གཅིག་ཏུ་ཟད་པའི་སྐྱོན་དང་། ངན་སོང་ལས་ཐར་དཀའ་བའི་སྐྱོན་དང་། སྐྱོན་དེ་རྣམས་བསལ་བའི་ཕྱིར་སྦྱིན་པའི་རྗེས་སུ་ཚུལ་ཁྲིམས་བསྟན་པའི་ཚུལ་བཞི།
Enumeration Block 18:
གསུམ་པ་ས་གསུམ་པ་འོད་བྱེད་པ་བཤད་པ་ལ། ཁྱད་གཞི་སའི་ངེས་ཚིག་བཤད་པ། ཁྱད་ཆོས་སའི་ཡོན་ཏན། སའི་ཡོན་ཏན་བརྗོད་པའི་མཇུག་བསྡུ་བ་གསུམ།
Enumeration Block 19:
གཉིས་པ་ཁྱད་ཆོས་ས་ཡི་ཡོན་ཏན་ལ། ས་འདིར་ལྷག་པ་བཟོད་པའི་ཕར་ཕྱིན་བཤད་པ་དང་། ས་འདིར་འབྱུང་བའི་ཡོན་ཏན་གཞན་བཤད་པ་གཉིས། དང་པོ་ལ། ས་འདིར་བཟོད་པ་ལྷག་ཚུལ་དང་། བཟོད་པ་སྒོམ་ཚུལ། བཟོད་པའི་དབྱེ་བ་གསུམ།
Enumeration Block 20:
གཉིས་པ་བཟོད་པ་སྒོམ་ཚུལ་ལ། དོན་དམ་པའི་སྒོ་ནས་བཟོད་པ་སྒོམ་ཚུལ་དང་། ཀུན་རྫོབ་ཀྱི་སྒོ་ནས་བཟོད་པ་སྒོམ་ཚུལ་གཉིས།
Enumeration Block 21:
གཉིས་པ་ལ། ཁོང་ཁྲོ་བའི་སྐྱོན་ལ་བསམ་སྟེ་བཟོད་པ་སྒོམ་ཚུལ་དང་། བཟོད་པའི་ཕན་ཡོན་ལ་བསམ་སྟེ་བཟོད་པ་སྒོམ་ཚུལ་དང་། ཐུན་མོང་དུ་མཇུག་བསྡུ་བ་གསུམ། དང་པོ་ལ། དོན་མེད་པས་ཁྲོ་བར་མི་རིགས་པར་བསམ་སྟེ་བཟོད་པ་བསྒོམ་པ། ཕན་བྱེད་གནོད་པར་བསྒྱུར་མི་རིགས་པར་བསམ་སྟེ་བཟོད་པ་བསྒོམ་པ། ཁོང་ཁྲོ་སྡིག་པ་ཤིན་ཏུ་སྟོབས་ཆེ་བར་བསམ་སྟེ་བཟོད་པ་བསྒོམ་པ། འདི་ཕྱིར་འབྱུང་བའི་སྐྱོན་དུ་མར་བསམ་སྟེ་བཟོད་པ་སྒོམ་ཚུལ་དང་བཞི།
Enumeration Block 22:
གསུམ་པ་མཇུག་བསྡུ་ལ། ཕར་ཕྱིན་སྔ་མ་གསུམ་ཐུན་མོང་དུ་མཇུག་བསྡུ་བ་དང་། བྱེ་བྲག་ས་འདིའི་མཇུག་བསྡུ་བ་གཉིས།
Enumeration Block 23:
བཞི་པ་འོད་འཕྲོ་བཤད་པ་ལ་གསུམ། ས་འདིར་བརྩོན་འགྲུས་ལྷག་པ། སའི་ངེས་ཚིག་སྤང་བའི་ཁྱད་པར་གསུམ།
Enumeration Block 24:
ལྔ་པ་སྦྱང་དཀའ་བ་བཤད་པ་ལ། ཁྱད་གཞི་སའི་ངེས་ཚིག་དང་། ཁྱད་ཆོས་སའི་ཡོན་ཏན་གཉིས།
Enumeration Block 25:
གཉིས་པ་ས་དྲུག་པ་མངོན་དུ་གྱུར་པ་བཤད་པ་ལ། ཡུལ་ཅན་སའི་ངོ་བོ་མདོར་བསྟན། ཡུལ་སྟོང་ཉིད་རྒྱས་པར་བཤད། སའི་ཡོན་ཏན་བརྗོད་པའི་མཇུག་བསྡུ་བ་གསུམ།

Enumeration Block 1:
གསུམ་པ་མཇུག་བསྡུ་ལ། ཕར་ཕྱིན་སྔ་མ་གསུམ་ཐུན་མོང་དུ་མཇུག་བསྡུ་བ་དང་། བྱེ་བྲག་ས་འདིའི་མཇུག་བསྡུ་བ་གཉིས།
Enumeration Block 2:
བཞི་པ་འོད་འཕྲོ་བཤད་པ་ལ་གསུམ། ས་འདིར་བརྩོན་འགྲུས་ལྷག་པ། སའི་ངེས་ཚིག་སྤང་བའི་ཁྱད་པར་གསུམ།
Enumeration Block 3:
ལྔ་པ་སྦྱང་དཀའ་བ་བཤད་པ་ལ། ཁྱད་གཞི་སའི་ངེས་ཚིག་དང་། ཁྱད་ཆོས་སའི་ཡོན་ཏན་གཉིས།
Enumeration Block 4:
གཉིས་པ་ས་དྲུག་པ་མངོན་དུ་གྱུར་པ་བཤད་པ་ལ། ཡུལ་ཅན་སའི་ངོ་བོ་མདོར་བསྟན། ཡུལ་སྟོང་ཉིད་རྒྱས་པར་བཤད། སའི་ཡོན་ཏན་བརྗོད་པའི་མཇུག་བསྡུ་བ་གསུམ།
Enumeration Block 5:
གཉིས་པ་ལ། སྟོང་པ་ཉིད་ཀྱི་ཆེ་བ་བརྗོད་པ་དང་། ཆེ་བ་དེ་ལྡན་གྱི་སྟོང་ཉིད་དངོས་བཤད་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། ཇི་ལྟར་བཤད་པའི་ཚུལ་དང་། གང་ལ་བཤད་པའི་སྣོད་དང་། གང་བཤད་པའི་ཆོས་གསུམ།
Enumeration Block 7:
གཉིས་པ་ལ། གང་ལ་བཤད་པའི་སྣོད་ངོས་བཟུང་བ་དང་། དེ་ལ་བཤད་ན་ཡོན་ཏན་འབྱུང་ཚུལ་གྱི་སྒོ་ནས་ཉན་པར་བསྐུལ་བ་གཉིས།
Enumeration Block 8:
གཉིས་པ་ལ། ཀུན་རྫོབ་ཐབས་ཀྱི་ཡོན་ཏན་འབྱུང་ཚུལ་དང་། དོན་དམ་ཡེ་ཤེས་ཀྱི་ཡོན་ཏན་འབྱུང་ཚུལ་གཉིས།
Enumeration Block 9:
གསུམ་པ་གང་བཤད་པའི་ཆོས་ལ། སྟོང་པ་ཉིད་རིགས་པས་གཏན་ལ་ཕབ་པ་དང་། གཏན་ལ་ཕབ་པའི་སྟོང་ཉིད་ཀྱི་དབྱེ་བ་བཤད་པ་གཉིས། དང་པོ་ལ། ཆོས་ཀྱི་བདག་མེད་རིགས་པས་གཏན་ལ་ཕབ་པ་དང་། གང་ཟག་གི་བདག་མེད་རིགས་པས་གཏན་ལ་ཕབ་པ་གཉིས། དང་པོ་ལ། རང་བཞིན་གྱིས་སྐྱེ་བ་རིགས་པས་དགག་པ་དང་། དེའི་ཕྱིར་ན་སྐྱེ་བ་རྟེན་ནས་འབྱུང་བ་ཙམ་གྱི་དོན་དུ་རིགས་པས་གྲུབ་ཚུལ། རིགས་པས་དཔྱད་པ་བྱས་པའི་འབྲས་བུ་ངོས་བཟུང་བ་གསུམ། དང་པོ་ལ་མཐའ་བཞིའི་སྐྱེ་བ་བདེན་པ་གཉིས་ཆར་དགག་པ། དེ་ལྟར་བཀག་པ་ལ་རྩོད་པ་སྤང་བ་གཉིས། དང་པོ་ལ། མཐའ་བཞིའི་སྐྱེ་བ་མེད་པའི་དམ་བཅའི་སྒོ་ནས་མདོར་བསྟན་པ། དེ་རིགས་པའི་སྒོ་ནས་རྒྱས་པར་བཤད། དེ་ལྟར་གྲུབ་པའི་དོན་གྱིས་མཇུག་བསྡུ་བ་གསུམ།
Enumeration Block 10:
གཉིས་པ་ལ། བདག་ལས་སྐྱེ་བ་དགག་པ། གཞན་ལས་སྐྱེ་བ་དགག་པ། གཉིས་ཀ་ལས་སྐྱེ་བ་དགག་པ། རྒྱུ་མེད་ལས་སྐྱེ་བ་དགག་པ་བཞི། དང་པོ་ལ། འགྲེལ་པ་མཛད་པའི་རིགས་པས་དགག་པ་དང་། སངས་རྒྱས་བསྐྱངས་དང་། ཟླ་བ། ཀླུ་སྒྲུབ། མཆན། བསྟན་བཅོས་མཛད་པའི་རིགས་པས་དགག་པ་གཉིས། དང་པོ་ལ། དེ་ཁོ་ན་ཉིད་དུ་བདག་སྐྱེ་དགག་པ་དང་། འཇིག་རྟེན་ཐ་སྙད་དུ་ཡང་བདག་སྐྱེ་མེད་པར་བསྟན་པ། དེ་གཉིས་ཀའི་གྲུབ་དོན་བསྡུ་བ་གསུམ། དང་པོ་ལ། རང་དང་ངོ་བོ་གཅིག་པའི་རྒྱུ་ལས་སྐྱེ་བ་དགག་པ་དང་། རྒྱུ་འབྲས་ངོ་བོ་གཅིག་པ་དགག་པ་གཉིས། དང་པོ་ལ། སྐྱེ་བ་དོན་མེད་དུ་ཐལ་བས་དགག་པ། སྐྱེ་བར་མི་རིགས་པས་དགག་པ། འབྲས་བུ་སྐྱེ་བ་སྐབས་མི་ཐོབ་པར་ཐལ་བས་དགག་པ། ས་བོན་ཐུག་མེད་དུ་སྐྱེ་བར་ཐལ་བས་དགག་པ་བཞི།
Enumeration Block 11:
གཉིས་པ་རྒྱུ་འབྲས་ངོ་བོ་གཅིག་པ་དགག་པ་ལ། རྒྱུ་འབྲས་ངོ་བོ་གཅིག་ན་གནས་སྐབས་མི་དམིགས་པར་ཐལ་བར་དགག་པ་དང་། གནས་སྐབས་ཐ་དད་པར་དམིགས་ན་རྒྱུ་འབྲས་ངོ་བོ་མི་གཅིག་པར་ཐལ་བས་དགག་པ་གཉིས། དང་པོ་ལ། རྒྱུ་འབྲས་རྣམ་པར་འགྱུར་བ་མི་འཐད་པ་དང་། དེས་ན་དབྱིབས་སོགས་ཐ་དད་མེད་པར་ཐལ་བས་དགག་པ་གཉིས།
Enumeration Block 12:
གཉིས་པ་ལ། གནས་སྐབས་ཐ་དད་ན་ངོ་བོ་གཅིག་ཏུ་མི་འཐད་པ་དངོས་དང་། དེ་ལྟར་འཐད་ན་གནས་སྐབས་གཉིས་སུ་གཉིས་ཀ་འཛིན་མི་འཛིན་མཚུངས་པར་ཐལ་བས་དགག་པ་གཉིས།
Enumeration Block 13:
གཉིས་པ། གཞན་སྐྱེ་དགག་པ་ལ། གཞན་སྐྱེ་འདོད་པ་སྤྱིར་དགག་པ་དང་སེམས་ཙམ་པའི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་གཉིས། དང་པོ་ལ། དེ་ཁོ་ན་ཉིད་དུ་གཞན་སྐྱེ་འདོད་པའི་ལུགས་སྤྱིར་དགག་པ་དང་། ཐ་སྙད་དུ་རང་བཞིན་གྱིས་སྐྱེ་བ་ཡོད་པར་འདོད་པའི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་གཉིས། དང་པོ་ལ། གཞན་སྐྱེ་དགག་པ་དངོས། བཀག་པ་ལ་འཇིག་རྟེན་གྱིས་གནོད་པ་སྤངས་པ། དེ་ལྟར་བཀག་པའི་ཡོན་ཏན་བསྟན་པ་གསུམ། དང་པོ་ལ། གཞན་སྐྱེ་སྤྱིར་དགག་པ། གཞན་སྐྱེ་བྱེ་བྲག་ཏུ་དགག་པ། འབྲས་བུ་ལ་མུ་བཞིར་དཔྱད་ནས་དགག་པ་གསུམ། དང་པོ་ལ། ཧ་ཅང་ཐལ་བས་དགག་པ། སྐྱོན་སྤོང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 14:
གཉིས་པ་ལ། སྐྱོན་སྤང་གི་ལན་དང་། ལན་དེ་དགག་པ་གཉིས།
Enumeration Block 15:
གཉིས་པ་བྱེ་བྲག་ཏུ་དགག་པ་ལ། རྒྱུ་འབྲས་སྔ་ཕྱི་བ་ལ་གཞན་སྐྱེ་དགག་པ། རྒྱུ་འབྲས་དུས་མཉམ་པ་ལ་གཞན་སྐྱེ་དགག་པ་གཉིས། དང་པོ་ལ་བཀག་པ་དངོས་དང་། སྐྱོན་སྤང་གི་ལན་དགག་པ་གཉིས།

Enumeration Block 1:
གཉིས་པ་རྒྱུ་འབྲས་ངོ་བོ་གཅིག་པ་དགག་པ་ལ། རྒྱུ་འབྲས་ངོ་བོ་གཅིག་ན་གནས་སྐབས་མི་དམིགས་པར་ཐལ་བར་དགག་པ་དང་། གནས་སྐབས་ཐ་དད་པར་དམིགས་ན་རྒྱུ་འབྲས་ངོ་བོ་མི་གཅིག་པར་ཐལ་བས་དགག་པ་གཉིས། དང་པོ་ལ། རྒྱུ་འབྲས་རྣམ་པར་འགྱུར་བ་མི་འཐད་པ་དང་། དེས་ན་དབྱིབས་སོགས་ཐ་དད་མེད་པར་ཐལ་བས་དགག་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ། གནས་སྐབས་ཐ་དད་ན་ངོ་བོ་གཅིག་ཏུ་མི་འཐད་པ་དངོས་དང་། དེ་ལྟར་འཐད་ན་གནས་སྐབས་གཉིས་སུ་གཉིས་ཀ་འཛིན་མི་འཛིན་མཚུངས་པར་ཐལ་བས་དགག་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ། གཞན་སྐྱེ་དགག་པ་ལ། གཞན་སྐྱེ་འདོད་པ་སྤྱིར་དགག་པ་དང་སེམས་ཙམ་པའི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་གཉིས། དང་པོ་ལ། དེ་ཁོ་ན་ཉིད་དུ་གཞན་སྐྱེ་འདོད་པའི་ལུགས་སྤྱིར་དགག་པ་དང་། ཐ་སྙད་དུ་རང་བཞིན་གྱིས་སྐྱེ་བ་ཡོད་པར་འདོད་པའི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་གཉིས། དང་པོ་ལ། གཞན་སྐྱེ་དགག་པ་དངོས། བཀག་པ་ལ་འཇིག་རྟེན་གྱིས་གནོད་པ་སྤངས་པ། དེ་ལྟར་བཀག་པའི་ཡོན་ཏན་བསྟན་པ་གསུམ། དང་པོ་ལ། གཞན་སྐྱེ་སྤྱིར་དགག་པ། གཞན་སྐྱེ་བྱེ་བྲག་ཏུ་དགག་པ། འབྲས་བུ་ལ་མུ་བཞིར་དཔྱད་ནས་དགག་པ་གསུམ། དང་པོ་ལ། ཧ་ཅང་ཐལ་བས་དགག་པ། སྐྱོན་སྤོང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། སྐྱོན་སྤང་གི་ལན་དང་། ལན་དེ་དགག་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་བྱེ་བྲག་ཏུ་དགག་པ་ལ། རྒྱུ་འབྲས་སྔ་ཕྱི་བ་ལ་གཞན་སྐྱེ་དགག་པ། རྒྱུ་འབྲས་དུས་མཉམ་པ་ལ་གཞན་སྐྱེ་དགག་པ་གཉིས། དང་པོ་ལ་བཀག་པ་དངོས་དང་། སྐྱོན་སྤང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། ལན་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ། ཕར་ལན་འདི་ལ་དམ་བཅའ། རིགས་པ། འབྲས་བུ་དངོས་མེད་ཀྱང་དེ་སྐྱེ་བའི་བྱ་བ་ཡོད་སྙམ་པ་དགག་པ་གསུམ་རིམ་པར།
Enumeration Block 8:
གཉིས་པ། དེ་ལྟར་བཀག་པ་ལ་འཇིག་རྟེན་གྱིས་གནོད་པ་སྤང་བ་ལ། འཇིག་རྟེན་གྱིས་གནོད་པའི་རྩོད་པ་བཀོད་པ་དང་། དེའི་ལན་བསྟན་པ་གཉིས།
Enumeration Block 9:
གཉིས་པ་ལ། འཇིག་རྟེན་པས་གཞན་སྐྱེ་ཁས་བླངས་ཀྱང་འཇིག་རྟེན་པས་མི་གནོད་པའི་ཚུལ་དང་། འཇིག་རྟེན་ཐ་སྙད་དུ་ཡང་རང་བཞིན་གྱིས་གྲུབ་པའི་གཞན་སྐྱེ་མེད་པས་འཇིག་རྟེན་པས་མི་གནོད་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཡུལ་དང་ཡུལ་ཅན་ཕྱིན་ཅི་མ་ལོག་པ་དང་ལོག་པའི་དབྱེ་བས་བདེན་གཉིས་ཀྱི་རྣམ་གཞག་མདོར་བསྟན་པ། དེ་ཉིད་རྒྱས་པར་བཤད་པ། དེ་དག་གི་ཕྱིར་ན་ཡུལ་གང་ལ་འཇིག་རྟེན་གྱིས་མི་གནོད་པ་དང་གནོད་པའི་ཁྱད་པར་བསྟན་པས་མཇུག་བསྡུ་བ་གསུམ།
Enumeration Block 10:
གཉིས་པ་ལ། ཡུལ་ཅན་ཚད་མའི་སྒོ་ནས་འཇིག་རྟེན་གྱིས་མི་གནོད་པའི་ཚུལ་དང་། ཡུལ་བདེན་གཉིས་ཀྱི་སྒོ་ནས་འཇིག་རྟེན་གྱིས་མི་གནོད་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཐ་སྙད་དཔྱོད་བྱེད་ཀྱི་ཚད་མ་བསྟན་པ་དང་། དེས་དོན་དམ་དཔྱོད་བྱེད་ཀྱི་ཚད་མ་ལ་མི་གནོད་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཡུལ་ཅན་ཚད་མ་དང་ཚད་མིན་གྱི་དབྱེ་བ་དང་། དེས་ཡུལ་འཇལ་ཚུལ་གཉིས།
Enumeration Block 11:
གཉིས་པ་ལ། ཡུལ་ཡང་ལོག་གི་ཁྱད་པར་སྤྱིར་བསྟན་པ་དང་། བྱེ་བྲག་ཏུ་ཞེན་ཡུལ་ལ་འཁྲུལ་བའི་ཞེན་ཡུལ་ཐ་སྙད་དཔྱོད་བྱེད་ཀྱི་ཚད་མ་དེའི་ངོར་ཡང་བདེན་པར་མི་འགྲུབ་པའི་ཚུལ་གཉིས།
Enumeration Block 12:
གཉིས་པ་ལ་ཡུལ་ཕྱིན་ཅི་ལོག་པ་ཀུན་རྫོབ་བདེན་པ་ངེས་ཚིག་གི་སྒོ་ནས་བཤད་པ་དང་། ཕྱིན་ཅི་མ་ལོག་པ་དོན་དམ་བདེན་པ་དཔེའི་སྒོ་ནས་བསྟན་པ་གཉིས།
Enumeration Block 13:
གསུམ་པ། མཇུག་བསྡུ་བ་ལ། དེ་ཁོ་ན་ཉིད་ལ་དཔྱད་པའི་སྐབས་སུ་འཇིག་རྟེན་གྱིས་མི་གནོད་པའི་ཚུལ་དང་། འཇིག་རྟེན་རང་གི་དོན་ལ་འཇིག་རྟེན་གྱིས་གནོད་ཚུལ་གཉིས། དང་པོ་ལ། འཇིག་རྟེན་ཚད་མར་མི་རིགས་པའི་ཚུལ་དང་། དེས་ན་ཚད་མིན་གྱིས་ཚད་མ་ལ་མི་གནོད་པར་བསྟན་པ་གཉིས།
Enumeration Block 14:

Enumeration Block 6:
གཉིས་པ་སེམས་ཙམ་གྱི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་ལ། ཕྱོགས་སྔ་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། རིགས་པས་དགག་པ་དང་། སེམས་ཙམ་དུ་གསུང་པའི་ལུང་གི་དགོངས་དོན་བཤད་པ་གཉིས། དང་པོ་ལ། ཕྱི་རོལ་མེད་པ་ཤེས་པ་རང་བཞིན་གྱིས་གྲུབ་པ་དགག་པ་དང་། གཞན་དབང་རང་བཞིན་གྱིས་གྲུབ་པ་དགག་པ་གཉིས། དང་པོ་ལ། ཕྱི་རོལ་མེད་པའི་ཤེས་པ་རང་གི་ངོ་བོ་དགག་པ་དང་། དེ་ལས་བེམ་པོར་སྣང་བའི་བག་ཆགས་སྨིན་པའི་ཚུལ་བཤད་པ་དགག་པ། དེ་ལྟར་བཀག་པའི་མཇུག་བསྡུ་བ་གསུམ། དང་པོ་ལ། ཕྱི་རོལ་མེད་པར་ཤེས་པ་རང་བཞིན་གྱིས་གྲུབ་པའི་དཔེ་དགག་པ། བག་ཆགས་ཀྱི་ནུས་པ་ལས་དོན་གྱིས་སྟོང་པའི་ཤེས་པ་སྐྱེ་བའི་དོན་དགག་པ་གཉིས། དང་པོ་ལ། རྨི་ལམ་གྱི་དཔེ་དགག་པ་དང་། སྐྲ་ཤད་མཐོང་བའི་དཔེ་དགག་པ་གཉིས། དང་པོ་ལ། དྲི་བ་དང་འདོད་པ་དེ་དགག་པ་གཉིས།
Enumeration Block 8:

Enumeration Block 17:

Enumeration Block 18:
གཉིས་པ་སེམས་ཙམ་པའི་སྒྲུབ་བྱེད་གཞན་དོན་མེད་པར་སྟོན་པ་ལ། རིགས་པའི་སྒྲུབ་བྱེད་མེད་པ། ལུང་གི་སྒྲུབ་བྱེད་མེད་པ། དཔེས་སྒྲུབ་བྱེད་མེད་པ་གསུམ།

གསུམ་པ་གཉིས་ཀ་ལས་སྐྱེ་བ་དགག་པ་ལ། གོང་གི་རིགས་པ་རྣམས་ཀྱིས་ཁེགས་པར་སྟོན་པ་དང་། གོང་མ་གཉིས་ལས་ཀྱང་མི་འཐད་པར་སྟོན་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་འཇིག་རྟེན་ཕ་རོལ་མེད་པ་དགག་པ་ལ། རྒྱང་འཕེན་པའི་བློ་འཇིག་རྟེན་ཕ་རོལ་མེད་པར་རྟོག་པ་ལ་ཚད་མ་མིན་པར་སྟོན་པ། ཕྱིན་ཅི་ལོག་གི་བློ་ཡིན་པར་སྟོན་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། རྒྱང་འཕེན་པའི་བློ་དེ་འདྲ་བ་དངོས་པོའི་གནས་ཚུལ་ལ་ཕྱིན་ཅི་ལོག་ཏུ་ཞུགས་པའི་བློ་ཡིན་པར་སྒྲུབ་པ་དང་། དེའི་དཔེ་ལ་རྩོད་པ་སྤོང་བ་གཉིས།
Enumeration Block 5:
དེའི་སྐབས་ནི་གཉིས་ཏེ། གཅིག་ནི་འབྱུང་བའི་རང་བཞིན་ཁོང་དུ་ཆུད་པའི་སྐབས་དང་། གཞན་ནི་འཇིག་རྟེན་གཞན་ལ་སྐུར་པ་འདེབས་པའི་སྐབས་སོ། །

Enumeration Block 1:
དེའི་སྐབས་ནི་གཉིས་ཏེ། གཅིག་ནི་འབྱུང་བའི་རང་བཞིན་ཁོང་དུ་ཆུད་པའི་སྐབས་དང་། གཞན་ནི་འཇིག་རྟེན་གཞན་ལ་སྐུར་པ་འདེབས་པའི་སྐབས་སོ། །
Enumeration Block 2:
གཉིས་པ་ལ། རྒྱང་འཕེན་པའི་བློ་དེ་འདྲ་བ་དངོས་པོའི་གནས་ཚུལ་ལ་ཕྱིན་ཅི་ལོག་ཏུ་ཞུགས་པའི་བློ་ཡིན་པར་སྒྲུབ་པ་དང་། དེའི་དཔེ་ལ་རྩོད་པ་སྤོང་བ་གཉིས།
Enumeration Block 3:
རྩོད་པ་སྤོང་བ་ལ། རང་བཞིན་དེ་ལྟར་ཡིན་ན་ཐམས་ཅད་ཀྱི་མཐོང་བར་ཐལ་བའི་རྩོད་སྤོང་དང་། སྣང་གཞི་མེད་ན་ཐ་སྙད་དུ་ཡང་མི་སྣང་བར་ཐལ་བའི་རྩོད་སྤང་གཉིས། དང་པོ་ལ། རང་བཞིན་མི་སྣང་བའི་རྒྱུ་བསྟན་པ་དང་། རྒྱུ་ཡང་རང་བཞིན་མེད་པར་བསྟན་པ་གཉིས། དང་པོ་ལ། རྒྱུ་གང་གིས་རང་བཞིན་མི་མཐོང་ཚུལ་དང་། དེ་དཔེས་སྒྲུབ་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ། དེ་ལྟར་གཞི་ཅུང་ཟད་ཀྱང་མེད་ན་ཐ་སྙད་དུ་ཡང་མི་སྣང་བར་ཐལ་བའི་རྩོད་སྤོང་ལ། རྩོད་པ་དངོས་དང་། དེའི་ལན་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། དཔེའི་སྒོ་ནས་རྩོད་པ་དེ་མ་ངེས་པར་སྟོན་པ་དང་། དོན་དུ་རང་བཞིན་གྱིས་མ་སྐྱེས་པ་དང་ཐ་སྙད་དུ་སྣང་བ་མི་འགལ་བར་སྟོན་པ་གཉིས། དང་པོ་ལ། བསྟན་བཤད་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ་གཟུགས་བརྙན་སོགས་མི་སྣང་བར་ཐལ་བ་འཕེན་པ་དང་། དེ་ཡི་ཕྱིར་ན་གཏན་ཚིགས་དེ་མ་ངེས་པར་སྟོན་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། རང་བཞིན་གྱིས་སྐྱེ་བ་བདེན་པ་གཉིས་ཆར་མེད་པར་སྟོན་པ། སྐྱེ་བ་མེད་ཀྱང་སྣང་བར་མི་འགལ་བར་སྒྲུབ་པ་གཉིས། དང་པོ་ལ། རང་བཞིན་གྱིས་སྐྱེ་བ་མེད་པར་བསྟན་པ་དངོས་དང་། ལུང་གིས་ཀྱང་དེ་ལྟར་བསྟན་ཚུལ་གཉིས།
Enumeration Block 8:
རྟེན་འབྱུང་ཙམ་དུ་སྟོན་པ་ལ། མཐའ་བཞིར་མི་སྐྱེ་བའི་གནད་ཀྱིས་ཆོས་རྣམས་རྟེན་འབྱུང་ཙམ་དུ་བསྟན་པ་དང་། རྟེན་འབྱུང་གི་རིགས་པ་དེ་ཡིས་ལྟ་ངན་མ་ལུས་པ་གཅོད་པའི་བསྔགས་པ་གཉིས།
Enumeration Block 9:
གསུམ་པ་རིགས་པས་དཔྱད་པའི་འབྲས་བུ་ངོས་བཟུང་བ་ལ། དཔྱད་པའི་འབྲས་བུ་བསྟན་པ་དང་། འབྲས་བུ་དེའི་རྒྱུ་དཔྱད་པ་དགོས་ཚུལ་བཤད་པ་གཉིས། དང་པོ་ལ། རྟོག་རྣམས་ལྡོག་པའི་རྒྱུ་མཚན་དང་། རྒྱུ་མཚན་དེ་ལྡན་གྱིས་རྟོག་པ་ལོག་པ་དེ་དཔྱོད་པའི་འབྲས་བུར་བསྟན་པ་གཉིས།
Enumeration Block 10:
གཉིས་པ་ལ། དེ་ཁོ་ན་ཉིད་དཔྱོད་པ་ལ་སྐྱོན་མེད་པས་དཔྱད་དགོས་ཚུལ་དང་། ཡོན་ཏན་ཡོད་པས་དཔྱད་དགོས་ཚུལ་གཉིས།
Enumeration Block 11:
གཉིས་པ་གང་ཟག་གི་བདག་མེད་རིགས་པས་གཏན་ལ་ཕབ་པ་ལ་ཐར་འདོད་ཀྱིས་ཐོག་མར་བདག་དགག་དགོས་པའི་ཚུལ་དང་། དེ་འགོག་བྱེད་ཀྱི་རིགས་པ་བསྟན་པ་གཉིས།
Enumeration Block 12:
གཉིས་པ་ལ། བདག་རྫས་ཡོད་དུ་འདོད་པའི་ལུགས་དགག་པ་དང་། བདག་བརྟེན་ནས་བཏགས་པ་ཙམ་དུ་བསྟན་པ་གཉིས། དང་པོ་ལ། བདག་ཕུང་ཐ་དད་དུ་འདོད་པ་དགག་པ། བདག་ཕུང་གཅིག་ཏུ་འདོད་པ་དགག་པ། བདག་ཕུང་གཅིག་ཐ་དད་གང་དུའང་བརྗོད་དུ་མེད་པར་དགག་པ་གསུམ། དང་པོ་ལ། ཕྱོགས་སྔ་མའི་ལུགས་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 13:
གཉིས་པ་ལ་རྟག་དངོས་ཀྱི་བདག་དེ་འདྲ་བ་མི་སྲིད་པས་དགག་པ་དང་། ཕུང་པོ་ལས་ཐ་དད་མེད་པས་དགག་པ་གཉིས། དང་པོ་ལ། འགོག་བྱེད་ཀྱི་རིགས་པ་སྤྱིར་བསྟན་པ་དང་། དེས་རྟག་དངོས་ཀྱི་བདག་འདོད་པའི་བྱེ་བྲག་མི་འདྲ་བ་ཀུན་ཀྱང་འཇོམས་པར་བསྟན་པ་གཉིས།
Enumeration Block 14:
གཉིས་པ་བདག་ཕུང་གཅིག་ཏུ་འདོད་པ་དགག་པ་ལ། ཕྱོགས་སྔ་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 15:
གཉིས་པ་ལ་བདག་ཕུང་གཅིག་པ་འདོད་ཚུལ་སྤྱིར་དགག་པ་དང་། ཕུང་པོ་དང་འབྲེལ་བར་བདག་ཏུ་རྟོག་ཚུལ་གཞན་དགག་པ་གཉིས། དང་པོ་ལ། ཕུང་པོར་བདག་ལྟའི་དམིགས་པར་མི་འཐད་པའི་རིགས་པ་བརྗོད་པ་དང་། ཕུང་པོ་ལ་དམིགས་པ་གསུངས་པའི་དོན་བཤད་པ་གཉིས། དང་པོ་ལ། བདག་ཕུང་གཅིག་པ་སྤྱིར་དགག་པ་དང་། ཕྱོགས་སྔའི་འདོད་པ་དང་ནང་འགལ་བའི་སྒོ་ནས་ཁྱད་པར་དུ་དགག་པ་གཉིས།
Enumeration Block 16:
གཉིས་པ་ལ་ཕྱོགས་སྔ་བ་རང་གི་འདོད་པ་དང་འགལ་བ། ལུང་དང་འགལ་བ། རིགས་པ་དང་འགལ་བ་གསུམ། དང་པོ་ལ། བཀག་པ་དངོས་དང་། དེ་ལྟར་བཀག་པའི་མཇུག་བསྡུ་བ་གཉིས། དང་པོ་ལ། བདག་ཏུ་འཛིན་པ་ཕྱིན་ཅི་ལོག་མ་ཡིན་པར་ཐལ་བས་དགག་པ། བདག་ཆད་པར་ཐལ་བས་དགག་པ། མྱང་འདས་བསྒྲུབ་པ་དོན་མེད་དུ་ཐལ་བས་དགག་པ། ལས་འབྲས་ཀྱི་རྣམ་གཞག་མི་འཐད་པས་དགག་པ་བཞི་ལས།
Enumeration Block 17:
བཞི་པ་ལ་དངོས་དང་། དེའི་ལན་དགག་པ་གཉིས། དང་པོ་ལ། ལས་བྱས་པ་ཆུད་ཟ་བའི་སྐྱོན་དུ་ཐལ་བ་དང་། མ་བྱས་པ་དང་འཕྲད་པར་ཐལ་བས་དགག་པ་གཉིས།
Enumeration Block 18:
གསུམ་པ་རིགས་པ་དང་འགལ་ཚུལ་ལ། ཕུང་པོ་བདག་ལྟའི་དམིགས་པ་ཡིན་ན་བདག་མེད་མཐོང་ཚེ་དངོས་རྣམས་མེད་པར་ཐལ་བས་དགག་པ། ཕུང་སོགས་ཡོད་ན་བདག་ཀྱང་མི་ཁེགས་པས་ཆགས་སོགས་མི་ལྡོག་པར་ཐལ་བས་དགག་པ་གཉིས། དང་པོ་ལ་དངོས་དང་། དེའི་ཉེས་སྤོང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 19:
གཉིས་པ་མདོ་ལས་ཕུང་པོ་བདག་ལྟའི་དམིགས་པ་གསུངས་པའི་དོན་བཤད་པ་ལ། ལུང་གི་དོན་ཕུང་པོ་བདག་ཏུ་འདོད་པ་མིན་པར་བསྟན་པ། རྟེན་ནས་བརྟགས་པའི་བདག་ཙམ་ཡིན་པར་སྟོན་པ་གཉིས། དང་པོ་ལ། ལུང་དོན་ཕུང་པོ་བདག་ཏུ་བཞེད་པར་འདོད་པ་ཕྱོགས་སྔའི་ལུགས་བཀོད་པ་དང་། དེ་བཀག་པ་གཉིས།
Enumeration Block 20:
གཉིས་པ་ལ། ལུང་གི་དགོངས་པ་དགག་བྱ་གཅོད་ཕྱོགས་ནས་ཡིན་པར་བསྟན་པ། གལ་ཏེ་སྒྲུབ་ཕྱོགས་ནས་ཡིན་དུ་ཆུག་ཀྱང་དེས་ཕྱོགས་སྔའི་འདོད་པ་ལ་མི་ཕན་པའི་ཚུལ་གཉིས། དང་པོ་ལ། བསྟན་བཤད་གཉིས།
Enumeration Block 21:
གཉིས་པ་ལ། ཕུང་པོ་བདག་ཡིན་ན་ཚོགས་པ་ལས་རེ་རེ་བ་མིན་ཚུལ་དང་། དེ་ལྟར་ན་ཕྱོགས་སྔའི་འདོད་པ་དང་འགལ་ཚུལ་གཉིས།
Enumeration Block 22:
གཉིས་པ་ལ་ཇི་ལྟར་འགལ་ཚུལ་དང་། དེའི་ཉེས་སྤོང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 23:
གཉིས་པ་ཚོགས་དང་ཚོགས་ཅན་ངོ་བོ་གཅིག་པས་སྐྱོན་དེ་མེད་དོ་ཞེས་པའི་ཉེས་སྤོང་གི་ལན་ལ། མདོ་ཡི་ལུང་དོན་དང་མི་འབྲེལ་བས་དགག་པ་དང་། རིགས་པ་དང་འགལ་བས་དགག་པ་གཉིས། དང་པོ་ལ། དཔེ་དཔེ་ཅན་གྱི་སྒོ་ནས་ཚོགས་པ་ཙམ་བདག་ཡིན་པར་དགག་པ་དང་། དེའི་ཉེས་སྤོང་གི་ལན་དགག་པ་གཉིས། དང་པོ་ལ། ཚོགས་པ་ཙམ་བདག་ཡིན་ན་དཔེ་ཤིང་རྟའི་ཡན་ལག་ཚོགས་པ་ཤིང་རྟར་ཐལ་བས་དགག་པ། དཔེ་དེ་བཞིན་དཔེ་ཅན་བདག་ཀྱང་ཕུང་པོ་ལ་བརྟེན་ནས་བཏགས་པར་གསུངས་པས་ཚོགས་ཙམ་བདག་མིན་པར་བསྟན་པ་གཉིས།

Enumeration Block 1:
གསུམ་པ་རིགས་པ་དང་འགལ་ཚུལ་ལ། ཕུང་པོ་བདག་ལྟའི་དམིགས་པ་ཡིན་ན་བདག་མེད་མཐོང་ཚེ་དངོས་རྣམས་མེད་པར་ཐལ་བས་དགག་པ། ཕུང་སོགས་ཡོད་ན་བདག་ཀྱང་མི་ཁེགས་པས་ཆགས་སོགས་མི་ལྡོག་པར་ཐལ་བས་དགག་པ་གཉིས། དང་པོ་ལ་དངོས་དང་། དེའི་ཉེས་སྤོང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་མདོ་ལས་ཕུང་པོ་བདག་ལྟའི་དམིགས་པ་གསུངས་པའི་དོན་བཤད་པ་ལ། ལུང་གི་དོན་ཕུང་པོ་བདག་ཏུ་འདོད་པ་མིན་པར་བསྟན་པ། རྟེན་ནས་བརྟགས་པའི་བདག་ཙམ་ཡིན་པར་སྟོན་པ་གཉིས། དང་པོ་ལ། ལུང་དོན་ཕུང་པོ་བདག་ཏུ་བཞེད་པར་འདོད་པ་ཕྱོགས་སྔའི་ལུགས་བཀོད་པ་དང་། དེ་བཀག་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། ལུང་གི་དགོངས་པ་དགག་བྱ་གཅོད་ཕྱོགས་ནས་ཡིན་པར་བསྟན་པ། གལ་ཏེ་སྒྲུབ་ཕྱོགས་ནས་ཡིན་དུ་ཆུག་ཀྱང་དེས་ཕྱོགས་སྔའི་འདོད་པ་ལ་མི་ཕན་པའི་ཚུལ་གཉིས། དང་པོ་ལ། བསྟན་བཤད་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། ཕུང་པོ་བདག་ཡིན་ན་ཚོགས་པ་ལས་རེ་རེ་བ་མིན་ཚུལ་དང་། དེ་ལྟར་ན་ཕྱོགས་སྔའི་འདོད་པ་དང་འགལ་ཚུལ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ་ཇི་ལྟར་འགལ་ཚུལ་དང་། དེའི་ཉེས་སྤོང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ཚོགས་དང་ཚོགས་ཅན་ངོ་བོ་གཅིག་པས་སྐྱོན་དེ་མེད་དོ་ཞེས་པའི་ཉེས་སྤོང་གི་ལན་ལ། མདོ་ཡི་ལུང་དོན་དང་མི་འབྲེལ་བས་དགག་པ་དང་། རིགས་པ་དང་འགལ་བས་དགག་པ་གཉིས། དང་པོ་ལ། དཔེ་དཔེ་ཅན་གྱི་སྒོ་ནས་ཚོགས་པ་ཙམ་བདག་ཡིན་པར་དགག་པ་དང་། དེའི་ཉེས་སྤོང་གི་ལན་དགག་པ་གཉིས། དང་པོ་ལ། ཚོགས་པ་ཙམ་བདག་ཡིན་ན་དཔེ་ཤིང་རྟའི་ཡན་ལག་ཚོགས་པ་ཤིང་རྟར་ཐལ་བས་དགག་པ། དཔེ་དེ་བཞིན་དཔེ་ཅན་བདག་ཀྱང་ཕུང་པོ་ལ་བརྟེན་ནས་བཏགས་པར་གསུངས་པས་ཚོགས་ཙམ་བདག་མིན་པར་བསྟན་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་རིགས་པ་དང་འགལ་བ་ལ། འགལ་བ་བརྗོད་པ་དང་། དེའི་ཉེས་སྤོང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 8:
གཉིས་པ་མདོ་ལས་བདག་བཏགས་པར་གསུངས་པ་ལ། མདོ་ལས་ཕུང་སོགས་བདག་ཏུ་མ་གསུངས་ཞིང་དེ་རྣམས་ལ་བརྟེན་ནས་བཏགས་པར་ཇི་ལྟར་གསུངས་ཚུལ་དང་། གསུངས་པ་ལྟར་ངར་འཛིན་ལྷན་སྐྱེས་ཀྱིས་ཀྱང་དེ་རྣམས་ཐུན་མོང་དང་། རེ་རེ་བ་ཚོགས་པ་གསུམ་གང་ཡང་བདག་ཏུ་མི་དམིགས་པའི་ཚུལ་དང་། ངར་འཛིན་ལྷན་སྐྱེས་ཀྱི་དམིགས་ཡུལ་དེ་སུན་མ་ཕྱུང་བར་བདག་མེད་རྟོགས་པར་འདོད་པའི་ལུགས་འབྲེལ་མེད་དུ་བསྟན་པ་གསུམ།
Enumeration Block 9:
གསུམ་པ་ལ་དོན་དང་། དེའི་དཔེ་གཉིས།
Enumeration Block 10:
གཉིས་པ་ཕུང་པོ་དང་འབྲེལ་བར་བདག་ཏུ་རྟོག་ཚུལ་གྱི་ལྷག་མ་དགག་པ་ལ། སྔར་མ་བཤད་པའི་ལྷག་མ་གསུམ་དགག་པ་དང་། ཐུན་མོང་དུ་མཇུག་བསྡུ་བ་གཉིས། དང་པོ་ལ་རྟེན་དང་བརྟེན་པར་གྲུབ་པ་དགག་པ་དང་། བདག་ལ་ཕུང་པོ་ལྡན་པར་འདོད་པ་དགག་པ་གཉིས།
Enumeration Block 11:
གཉིས་པ་ལ། འཇིག་ལྟ་ཉི་ཤུ་བསྡོམས་ཏེ་བཤད་པ་དང་། དེ་རྣམས་རྩ་བའི་འཇིག་ལྟ་ལ་གནས་ཤིང་ཀུན་བཏགས་ཡིན་པར་བསྟན་པ་གཉིས།
Enumeration Block 12:
གསུམ་པ་བརྗོད་མེད་ཀྱི་བདག་དགག་པ་ལ། ཕྱོགས་སྔ་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 13:
གཉིས་པ་ལ། དངོས་པོར་གྲུབ་ན་བརྗོད་དུ་ཡོད་པར་ཐལ་བས་དགག བརྗོད་དུ་མེད་ན་དངོས་པོར་མེད་པར་ཐལ་བས་དགག དེས་ན་དངོས་པོའི་ཆོས་གཉིས་དང་བྲལ་བས་དངོས་པོར་མི་འགྲུབ་པས་དགག་པ་གསུམ།
Enumeration Block 14:
གཉིས་པ་བདག་བརྟེན་ནས་བཏགས་པ་ཙམ་དུ་བསྟན་པ་ལ། བདག་མཐའ་བདུན་དུ་མེད་ཀྱང་བརྟེན་ནས་བཏགས་པ་ཤིང་རྟ་དང་འདྲ་བ་བསྟན་པ། དེས་དངོས་པོ་གཞན་ཀྱང་དེ་འདྲ་བའི་བཏགས་པར་བསྟན་པ་གཉིས། དང་པོ་ལ། བརྟེན་ནས་བཏགས་ཚུལ་དངོས་དང་། དེ་ལྟར་ཤེས་པའི་ཕན་ཡོན་གཉིས། དང་པོ་ལ། དཔེ་ཅན་བདག་མེད་ཚུལ་དང་། དེའི་དཔེ་ཤིང་རྟའི་ཚུལ་དང་སྦྱར་བ་གཉིས།
Enumeration Block 15:
གཉིས་པ་ལ། སྤྱི་དང་། བྱེ་བྲག་གཉིས།
Enumeration Block 16:
གཉིས་པ་ཚོགས་དབྱིབས་བྱེ་བྲག་ཏུ་དགག་པ་ལ། ཚོགས་ཙམ་ཤིང་རྟར་འདོད་པ་དགག་པ་དང་། དབྱིབས་ཙམ་ཤིང་རྟར་འདོད་པ་དགག་པ་གཉིས།
Enumeration Block 17:
གཉིས་པ་ལ་ཡན་ལག་གི་དབྱིབས་སོ་སོ་བ་ཤིང་རྟར་འདོད་པ་དགག་པ་དང་། ཚོགས་པའི་དབྱིབས་ཤིང་རྟར་འདོད་པ་དགག་པ་གཉིས། དང་པོ་ལ། ཡན་ལག་གི་སྔར་གྱི་དབྱིབས་ཁོ་ན་ཤིང་རྟར་འདོད་པ་དགག་པ་དང་། སྔར་ལས་གཞན་པའི་དབྱིབས་ཤིང་རྟར་འདོད་པ་དགག་པ་གཉིས།
Enumeration Block 18:
གཉིས་པ་ཚོགས་ཙམ་གྱི་དབྱིབས་ཤིང་རྟར་འདོད་པ་དགག་པ་ལ། ཚོགས་པ་ཙམ་གྱི་དབྱིབས་ཤིང་རྟར་འདོད་པ་བཀག་པ་དང་། རིགས་པ་དེས་རྒྱུ་སྟོང་པ་ལས་འབྲས་བུ་འབྱུང་བར་འཐད་པར་བསྟན་པ་གཉིས།
Enumeration Block 19:
གཉིས་པ་ལ། སྤྱིར་བསྟན་པ་དང་། བྱེ་བྲག་ཕྱེ་སྟེ་བཤད་པ་གཉིས།
Enumeration Block 20:
གཉིས་པ་བཏགས་པ་ཙམ་དུ་རྟོགས་པའི་ཕན་ཡོན་ལ་དཔེ་ཤིང་རྟ་དང་སྦྱར་ཏེ་བཤད་པ་དང་། དཔེ་ཅན་བདག་ལ་སྦྱར་ཏེ་བཤད་པ་གཉིས། དང་པོ་ལ། ཐ་སྙད་ཀྱི་རྣམ་གཞག་མི་འཇིག་པར་ཤིན་ཏུ་འཐད་པའི་ཡོན་ཏན་དང་། དོན་དམ་པ་བདེ་བླག་ཏུ་རྟོགས་པའི་ཕན་ཡོན་གཉིས། དང་པོ་ལ་མཐའ་བདུན་དུ་མ་དཔྱད་པར་གྲགས་པ་ཙམ་དུ་ཡོད་པར་བསྟན་པ་དང་། རང་བཞིན་མེད་ཀྱང་ལྟོས་ཏེ་བཏགས་པའི་ཐ་སྙད་དེས་དོན་གྲུབ་པའི་ཚུལ་གཉིས།
Enumeration Block 21:
གཉིས་པ་ལ་དངོས་དང་། དོགས་སྤང་གཉིས།
Enumeration Block 22:
གཉིས་པ་དཔེ་ཅན་དགག་པ་ལའང་། རང་བཞིན་མེད་ཀྱང་ཐ་སྙད་ཀྱི་རྣམ་བཞག་ཤིན་ཏུ་འཐད་པའི་ཚུལ་དང་། དོན་དམ་པ་མངོན་དུ་འགྱུར་ཚུལ་གཉིས།
Enumeration Block 23:
གཉིས་པ་ལ། ལམ་རྟག་ཆད་དང་བྲལ་བའི་ལྟ་བ་རྟོགས་པ་དང་། འབྲས་བུ་རྣམ་གྲོལ་ཐོབ་པར་བསྟན་པ་གཉིས།
Enumeration Block 24:
གཉིས་པ་ལ་བཏགས་པ་ཙམ་ཡིན་པས་ངར་འཛིན་ལྷན་སྐྱེས་ཀྱི་ཡུལ་སུན་ཕྱུང་ནུས་པ་དང་། དེ་སུན་ཕྱུང་བས་བདག་གི་བ་ཡང་མེད་ཚུལ། དེ་གཉིས་ཀ་མེད་ན་རྣམ་པར་གྲོལ་བ་འཐད་ཚུལ་གསུམ།
Enumeration Block 25:
གཉིས་པ་བདག་དང་ཤིང་རྟ་བརྟགས་པ་ཙམ་དུ་བསྟན་པའི་རིགས་པ་དེ་གཞན་ལ་བསྒྲེ་བ་ལ། བུམ་སྣམ་སོགས་ཆ་དང་ཆ་ཅན་སོགས་ལ་བསྒྲེ་བ་དང་། རྒྱུ་འབྲས་ལ་བསྒྲེ་བ་གཉིས།
Enumeration Block 26:
གཉིས་པ་ལ་དངོས་དང་། དེ་རང་ལ་མཚུངས་པའི་རྩོད་སྤོང་གཉིས། དང་པོ་ལ་རྒྱུ་འབྲས་རང་བཞིན་གྱིས་གྲུབ་ན་གང་སྔ་དྲིས་ནས་དགག་པ་དང་། རྒྱུ་འབྲས་ཕྲད་དམ་མ་ཕྲད་པར་སྐྱེད་དྲིས་ནས་དགག་པ་དང་། རྒྱུ་འབྲས་གཅིག་མ་གྲུབ་ན་གཅིག་ཤོས་ཀྱང་མ་གྲུབ་པར་སྟོན་པ། རྩོད་པ་དེ་རང་ལ་མི་མཚུངས་པའི་ཚུལ་དང་བཞི།
Enumeration Block 27:
གཉིས་པ་ཐལ་བ་དེ་རང་གི་སུན་འབྱིན་ལ་ཡང་མཚུངས་པའི་རྩོད་སྤོང་ལ། རྩོད་པ་དང་། དེའི་ལན་གཉིས། དང་པོ་ལ། ཕྲད་སོགས་རང་ལ་མཚུངས་པར་ཐལ་བས་རྩོད་པ་དང་། ཐལ་བ་དེ་འདྲ་བ་གཏན་ཚིགས་ཡང་དག་མིན་པའི་རྩོད་པ་དང་། རང་ཕྱོགས་མེད་པའི་སུན་ཅི་ཕྱིན་ཏུ་རྒོལ་བ་ཡིན་པའི་རྩོད་པ་གསུམ།
Enumeration Block 28:
གཉིས་པ་ལན་ལ། ཕྲད་སོགས་ཀྱི་ལན་བསྟན་པ་དང་། ལན་ལྷག་མ་གོང་དུ་བཤད་ཟིན་པར་བསྟན་པ་གཉིས། དང་པོ་ལ། རྩོད་པ་དེ་གཞན་ཕྱོགས་ལ་འགྱུར་གྱི་རང་ཕྱོགས་ལ་མི་འགྱུར་པར་མདོར་བསྟན། དེ་རིགས་པས་རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 29:

Enumeration Block 6:
གཉིས་པ་ལ། རྩོད་པ་དང་། ལན་གཉིས་དང་པོ་ལ། ཡུལ་སྐྱེ་མེད་རྟོགས་པར་མི་འཐད་པར་རྩོད་པ་དང་། ཡུལ་ཡུལ་ཅན་རོ་གཅིག་ན་ཡུལ་དེ་མཁྱེན་ནས་གཞན་ལ་སྟོན་པར་མི་འཐད་པའི་རྩོད་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལན་ལ་ཡུལ་སྐྱེ་མེད་རྟོགས་པར་འཐད་པའི་ལན་དང་། ཡུལ་ཡུལ་ཅན་ཐ་དད་དུ་མི་རྟོགས་ཀྱང་ཆོས་སྟོན་པར་འཐད་པ་གཉིས།
Enumeration Block 8:
གཉིས་པ་ལ་དངོས་དང་། དེའི་དཔེ་འགོད་པ་གཉིས།
Enumeration Block 9:
གཉིས་པ་བརྙེས་བྱ་བྱང་ཆུབ་ཀྱི་ངོ་བོ་ལ། རྟེན་སྐུའི་རྣམ་བཞག་དང་། བརྟེན་པ་ཡོན་ཏན་གྱི་ཁྱད་པར་གཉིས། དང་པོ་ལ། ཆོས་སྐུ། ལོངས་སྐུ། རྒྱུ་མཐུན་པའི་སྐུ་གསུམ་ལས།
Enumeration Block 10:
གསུམ་པ་ལ་སྐུའི་བ་སྤུའི་ཁུང་བུར་རང་གི་སྤྱོད་པ་ཀུན་སྟོན་ཚུལ། གནས་དེར་གཞན་གྱི་སྤྱོད་པ་ཀུན་སྟོན་ཚུལ། བཞེད་པ་ཕུན་ཚོགས་ལ་མངའ་དབང་བསྒྱུར་ཚུལ་གསུམ།
Enumeration Block 11:
གསུམ་པ་ལ་ཡུལ་གྱི་དབང་དུ་བྱས་པ་དང་། དུས་ཀྱི་དབང་དུ་བྱས་པ་གཉིས།
Enumeration Block 12:
གཉིས་པ་ཡོན་ཏན་ལ། ཡོན་ཏན་གྱི་གཙོ་བོ་སྟོབས་བཅུ་བཤད་པ། ཡོན་ཏན་ཀུན་བརྗོད་མི་ནུས་པའི་ཚུལ། ཡོན་ཏན་དེ་དག་ཤེས་པའི་ཕན་ཡོན་གསུམ། དང་པོ་ལ་བསྟན་བཤད་གཉིས།
Enumeration Block 13:
གཉིས་པ་ལ། ཡོན་ཏན་ཀུན་རྫོབ་མི་ནུས་པའི་ཚུལ་དང་། འདིར་ནི་ཅུང་ཟད་བརྗོད་པའང་ལུང་ལ་བརྟེན་ནས་ཡིན་ཚུལ་གཉིས།
Enumeration Block 14:
གསུམ་པ་བྱང་ཆུབ་བརྙེས་ནས་སྤྲུལ་པས་འགྲོ་དོན་མཛད་ཚུལ་ལ། སྟོན་པ་མཆོག་གི་སྤྲུལ་པའི་སྐུའི་རྣམ་ཐར་སྟོན་པ། བསྟན་པ་མཐར་ཐུག་ཐེག་པ་གཅིག་ཏུ་གྲུབ་པ། སྟོན་པ་དེ་ཉིད་མངོན་པར་བྱང་ཆུབ་པ་དང་། བཞུགས་པའི་དུས་ཀྱི་སྒོ་ནས་ཚད་མེད་པར་བསྟན་པ་གསུམ།
Enumeration Block 15:
གཉིས་པ་ལ་མཐར་ཐུག་ཐེག་པ་གཅིག་ཏུ་རིགས་པས་གྲུབ་ཚུལ་བརྗོད་པ་དང་། ཐེག་པ་གསུམ་དུ་བསྟན་པ་དྲང་དོན་དུ་བསྟན་པ་གཉིས།
Enumeration Block 16:
གསུམ་པ་ལ། མངོན་པར་བྱང་ཆུབ་པའི་དབང་དུ་བྱས་པ་དང་། རྟག་ཏུ་སྲིད་པར་བཞུགས་པའི་དབང་དུ་བྱས་པ་གཉིས།
Enumeration Block 17:
གཉིས་པ་ལ། མདོར་བསྟན་རྒྱས་བཤད་གཉིས།
Enumeration Block 18:
གཉིས་པ་ལ། འགྲོ་ལ་ཐུགས་བརྩེ་ཚད་མེད་པ་མངའ་ཚུལ་དང་། དེས་ཡུལ་སྡུག་བསྔལ་ཅན་གྱི་སེམས་ཅན་ཟད་པ་མེད་པས་མྱ་ངན་ལས་མི་འདའ་བའི་ཚུལ་གཉིས།
Enumeration Block 19:
གསུམ་པ་མཇུག་མཐར་ཕྱིན་པའི་བྱ་བ་ལ། ཇི་ལྟར་བརྩམས་པའི་ཚུལ་དང་། དེ་ལྟར་བརྩམས་པའི་དགེ་བ་བསྔོ་བ་གཉིས། དང་པོ་ལ། རྩོམ་ཚུལ་དངོས་དང་། དེ་ལྟར་བརྩམས་པའི་དགོས་པ་གཉིས། དང་པོ་ལ། གང་ལ་བརྟེན་ནས་རྩོམ་ཚུལ་དང་། དེ་ལྟར་བརྩམས་པའི་བསྟན་བཅོས་འདི་ཐུན་མོང་མ་ཡིན་པར་སྟོན་པ་གཉིས།
Enumeration Block 20:
གཉིས་པ་དགོས་པ་ལ། དངོས་དང་། དགོས་པ་དེ་ལྡན་གྱི་གཞུང་འདི་ཁོ་ན་འཛིན་པར་གདམས་པ་གཉིས།
Enumeration Block 21:
བཞི་པ་མཇུག་གི་དོན་ལ་སློབ་དཔོན་གང་གིས་མཛད་པ་དང་། ལོ་ཙཱ་བ་གང་གིས་བསྒྱུར་ཚུལ་གཉིས།
