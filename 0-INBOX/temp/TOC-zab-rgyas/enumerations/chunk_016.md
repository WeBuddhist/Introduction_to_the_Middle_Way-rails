Enumeration Block 1:
གཉིས་པ་སྒྲིབ་པ་གཉིས་ལམ་གང་དུ་ཚུལ་ཇི་ལྟར་སྤོང་བ་ལ། ཉོན་སྒྲིབ་སྤོང་ཚུལ་དང་། ཤེས་སྒྲིབ་སྤོང་ཚུལ་དང་གཉིས།
Enumeration Block 2:
གསུམ་པ་ཕར་ཕྱིན་དང་པོ་གསུམ་གྱི་ཁྱད་པར་གྱི་ཆོས་བཤད་པ་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 3:
བཞི་པ་ས་བཞི་པ་འོད་འཕྲོ་བ་བཤད་པ་ལ་གསུམ། ས་འདིར་བརྩོན་འགྲུས་ལྷག་པར་བསྟན་པ། སའི་ངེས་པའི་ཚིག་བསྟན་པ། སྤངས་པའི་ཁྱད་པར་བསྟན་པའོ། །
Enumeration Block 4:
གསུམ་པ་སྤངས་པའི་ཁྱད་པར་བསྟན་པ་ལ་ཚིག་དོན་དང་མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་གཉིས།
Enumeration Block 6:
ལྔ་པ་ས་ལྔ་པ་སྦྱང་དཀའ་བ་བཤད་པ་ལ། ས་ལྔ་པའི་ངེས་པའི་ཚིག་བཤད་པ་དང་། བསམ་གཏན་ལྷག་ཅིང་བདེན་པ་ལ་མཁས་པར་བསྟན་པའོ། །
Enumeration Block 7:
གཉིས་པ་བསམ་གཏན་ལྷག་ཅིང་བདེན་པ་ལ་མཁས་པར་བསྟན་པ་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 8:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
