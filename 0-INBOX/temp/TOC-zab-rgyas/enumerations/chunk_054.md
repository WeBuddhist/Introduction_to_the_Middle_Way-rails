Enumeration Block 1:
བདག་དང་ཤིང་རྟའི་དཔྱད་པ་དངོས་པོ་གཞན་ལ་རིགས་བསྒྲེ་བ་ལ་གསུམ། བུམ་སྣམ་སོགས་ཀྱི་དངོས་པོ་ལ་བསྒྲེ་བ། རྒྱུ་དང་འབྲས་བུའི་དངོས་པོ་ལ་བསྒྲེ་བ། དེ་ལ་གཞན་གྱི་རྩོད་པ་སྤངས་བའོ། །
Enumeration Block 2:
དེ་ལ་གཞན་གྱི་རྩོད་པ་སྤང་བ་ལ་གཉིས། རྒྱུ་འབྲས་རང་བཞིན་གྱིས་གྲུབ་པ་བཀག་པ་ལ་ཡང་སྐྱོན་མཚུངས་པའི་རྩོད་པ་དང་། རང་ལ་སྐྱོན་མི་མཚུངས་པའི་ལན་བསྟན་པའོ། །
Enumeration Block 3:
རང་ལུགས་ལ་མི་མཚུངས་པའི་ལན་བསྟན་པ་ལ་བཞི། རང་ཕྱོགས་ལ་སུན་འབྱིན་དང་སྒྲུབ་པ་འཐད་ཚུལ། གཞན་གྱི་ཐལ་བ་མི་མཚུངས་པའི་རྒྱུ་མཚན་གསལ་བར་བཤད། རང་བཞིན་མེད་པ་སྒྲུབ་ནུས་པ་བཞིན་ཏུ་གཞན་གྱིས་བཟློག་སྟེ་སྒྲུབ་མི་ནུས་པ། འདིར་མ་བཤད་པའི་སུན་འབྱིན་ལྷག་མ་ཤེས་པར་བྱེད་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཐ་སྙད་དུ་གཞན་ཕྱོགས་སུན་འབྱིན་པ་ཁས་ལེན་ཚུལ་དང་། རང་གི་ཕྱོགས་སྒྲུབ་པ་ཁས་ལེན་ཚུལ་ལོ། །
Enumeration Block 4:
རིགས་པས་གྲུབ་པའི་སྟོང་ཉིད་ཀྱི་རབ་དབྱེ་བཤད་པ་ལ་གཉིས། སྟོང་པ་ཉིད་ཀྱི་དབྱེ་བ་མདོར་བསྟན་པ་དང་། དབྱེ་བ་སོ་སོའི་དོན་རྒྱས་པ་བཤད་པའོ། །
Enumeration Block 5:
དབྱེ་བ་སོ་སོའི་དོན་རྒྱས་པར་བཤད་པ་ལ་གཉིས། སྟོང་ཉིད་བཅུ་དྲུག་ཏུ་ཕྱེ་བ་རྒྱས་པར་བཤད་པ་དང་། ང་སྟོང་ཉིད་བཞིར་ཕྱེ་བ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་བཞི། ནང་སྟོང་པ་ཉིད་ལ་སོགས་པ་བཞི་བཤད་པ་དང་། ཆེན་པོ་སྟོང་པ་ཉིད་ལ་སོགས་པ་བཞི་བཤད་པ་དང་། མཐའ་ལས་འདས་པ་སྟོང་པ་ཉིད་ལ་སོགས་པ་བཞི་བཤད་པ་དང་། ཆོས་ཐམས་ཅད་སྟོང་པ་ཉིད་ལ་སོགས་པ་བཞི་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ནང་སྟོང་པ་ཉིད་བཤད་པ་དང་། སྟོང་ཉིད་ལྷག་མ་གསུམ་བཤད་པའོ། །
Enumeration Block 6:
ཆོས་ཐམས་ཅད་སྟོང་པ་ཉིད་ལ་སོགས་པ་བཞི་བཤད་པ་ལ་གསུམ། ཆོས་ཐམས་ཅད་སྟོང་པ་ཉིད་བཤད་པ་དང་། རང་གི་མཚན་ཉིད་སྟོང་པ་ཉིད་བཤད་པ་དང་། མི་དམིགས་པ་དང་དངོས་པོ་མེད་པའི་ངོ་བོ་ཉིད་སྟོང་པ་ཉིད་བཤད་པའོ། །
Enumeration Block 7:
རང་གི་མཚན་ཉིད་སྟོང་པ་ཉིད་བཤད་པ་ལ་གསུམ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ། དོན་བསྡུ་བའོ། །
