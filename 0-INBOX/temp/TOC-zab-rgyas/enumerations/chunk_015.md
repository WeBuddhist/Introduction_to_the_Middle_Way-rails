Enumeration Block 1:
བཞི་པ་ས་འདིར་འབྱུང་བའི་ཡོན་ཏན་གཞན་བསྟན་པ་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་གཉིས།
Enumeration Block 2:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ།
Enumeration Block 3:
གཉིས་པ་རང་ལུགས་ལ་སྒྲིབ་པ་གཉིས་དང་དེ་ལམ་གང་དུ་ཚུལ་ཇི་ལྟར་སྤོང་བ་དང་གཉིས། དང་པོ་ལ། ཉོན་སྒྲིབ་བཤད་པ་དང་། ཤེས་སྒྲིབ་བཤད་པ་གཉིས།
Enumeration Block 4:
དེ་ལ་དབྱེ་ན། ཉོན་སྒྲིབ་ཀུན་བཏགས་དང་ལྷན་སྐྱེས་གཉིས།
Enumeration Block 5:
ཡང་ཉོན་སྒྲིབ་ཀུན་བཏགས་དང་ལྷན་སྐྱེས་གཉིས་པོ་རེ་རེ་ལ་ཡང་མངོན་གྱུར་དང་ས་བོན་གཉིས་གཉིས་ཡོད་དེ།
Enumeration Block 6:
ཤེས་སྒྲིབ་ལ་དབྱེ་ན་མངོན་གྱུར་པ་དང་། ས་བོན་གྱི་ཆ་གཉིས་ཡོད།
