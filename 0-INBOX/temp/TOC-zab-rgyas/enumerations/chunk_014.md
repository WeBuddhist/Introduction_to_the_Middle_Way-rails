Enumeration Block 1:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 2:
བྱང་སེམས་སྟོབས་ཆེ་བས་བྱང་སེམས་སྟོབས་ཆུང་བ་ལ་ཁྲོ་བ་དང་། བྱང་སེམས་སྟོབས་ཆུང་བས་བྱང་སེམས་སྟོབས་ཆེ་བ་ལ་ཁྲོ་བ་དང་། ཡུལ་དང་སྟོབས་གཉིས་ཀ་མཉམ་པས་མཉམ་པ་ལ་ཁྲོས་པ་གསུམ་མོ། །
Enumeration Block 3:
ཁྲོས་པའི་རྟེན་གྱི་སྒོ་ནས་བཅོམ་ཚུལ་གསུམ་ཡོད་དེ། བྱང་སེམས་སྟོབས་ཆེ་བས་ཆུང་བ་ལ་ཁྲོ་བས་དགེ་བ་འཇོམས་ཚུལ་དང་། ཆུང་བས་ཆེ་བ་ལ་ཁྲོས་པས་དེ་དང་། མཉམ་པའི་མཉམ་པ་ལ་ཁྲོ་བས་དེ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
བཅོམ་པ་དེ་ལ་དབྱེ་ན་བཅོམ་པ་རབ་འབྲིང་ཐ་མ་གསུམ་ཡོད་དེ།
Enumeration Block 5:
སྐབས་འདིར་དགེ་རྩ་བཅོམ་ཚུལ་ལ་བཅོམ་ཚུལ་གཉིས་ཡོད་དེ།
Enumeration Block 6:
བཅོམ་པ་དང་པོ་ལ་དུ་མ་ཡོད་དེ། བཅོམ་པ་ཆེ་བ་ལ་ནི་ལམ་གྱི་ཐོག་མ་གཞི་ནས་གོ་བགོ་དགོས་པ་དང་། འབྲིང་བསྐལ་པ་སླར་གོ་བགོ་དགོས་པ་དང་། ཐ་མ་ཚེ་དེའམ་སྐྱེ་བ་འགའ་ཞིག་ལ་སྔར་སླེབས་མཚམས་ཀྱི་དེ་མ་ཐག་གི་ལམ་དེ་སྐྱེ་མི་རུང་བར་བྱས་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
གཞན་ཡང་དགེ་རྩ་བཅོམ་ཚུལ་ལ་དུ་མ་ཡོད་དེ། རྣམ་སྨིན་གྱི་འབྲས་བུ་བཅོམ་ཡང་བྱེད་པ་རྒྱུ་མཐུན་གྱི་རྒྱུ་མ་བཅོམ་པས་དགེ་རྩ་དེ་སྐྱེ་སླ་བ་གཅིག་དང་། དེ་ལས་ལྡོག་པ་བྱེད་པ་རྒྱུ་མཐུན་བཅོམ་ཡང་རྣམ་སྨིན་མ་བཅོམ་པ་དང་། བྱང་སེམས་ཀྱི་ཚོགས་ལམ་དེ་ཁོང་ཁྲོས་མྱུར་བའི་ཤུགས་བཅོམ་པ་ལྟ་བུ་རྣམ་སྨིན་དང་རྒྱུ་མཐུན་གཉིས་མ་བཅོམ་ཀྱང་བུལ་དུ་བྱས་པ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
གཉིས་པ་བཟོད་པ་བསྟེན་པར་རིགས་པ་ལ་གཉིས། བཟོད་པའི་ཡོན་ཏན་མང་པོ་བསམ་པ་དང་། དོན་བསྡུས་ཏེ་བཟོད་པ་བསྟེན་པར་གདམས་པའོ། །
Enumeration Block 9:
བཟོད་པའི་ཕར་ཕྱིན་ལ་དབྱེ་ན། འཇིག་རྟེན་ལས་མ་འདས་པ་དང་འདས་པའི་བཟོད་པ་གཉིས་ཡོད་དེ།
Enumeration Block 10:
བཞི་པ་ས་འདིར་འབྱུང་བའི་ཡོན་ཏན་གཞན་བསྟན་པ་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་གཉིས།
Enumeration Block 11:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ།
