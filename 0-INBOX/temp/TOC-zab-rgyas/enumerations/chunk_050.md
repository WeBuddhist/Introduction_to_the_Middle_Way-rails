Enumeration Block 1:
ཆོས་ཀྱི་བདག་འཛིན་ཀུན་བཏགས་དང་ལྷན་སྐྱེས་གཉིས།
Enumeration Block 2:
གང་ཟག་གི་བདག་འཛིན་གྱི་བྱེ་བྲག་འཇིག་ལྟ་ལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་དབྱེ་བ་ལ་གཉིས་ཏེ།
Enumeration Block 4:
བདག་དང་བདག་གི་བ་རང་བཞིན་གྱིས་གྲུབ་པ་དགག་པ་ལ་གཉིས། གཞུང་གི་ཚིག་དོན་དང་། དེའི་མཐའ་དཔྱད་པ་གཉིས། དང་པོ་ལའང་གཉིས། བདག་རང་བཞིན་གྱིས་གྲུབ་པ་དགག་པ་དང་། བདག་གི་བ་རང་བཞིན་གྱིས་གྲུབ་པ་དགག་པའོ། །དང་པོ་ལ་དྲུག་སྟེ། གཞན་སྡེས་བཏགས་པའི་ཕུང་པོ་ལས་ངོ་བོ་ཐ་དད་པའི་བདག་དགག་པ་དང་། རང་སྡེས་བཏགས་པའི་ཕུང་བོ་ཉིད་བདག་ཏུ་འདོད་པ་དགག་པ་དང་། དེ་གཉིས་ཀྱི་ལྷག་མའི་འདི་ཉིད་ཕྱོགས་རྟེན་བརྟེན་པ་སོགས། གསུམ་དགག་པ་དང་། དེ་ཉིད་གཞན་ཉིད་དུ་མེད་པའི་གང་ཟག་རྫས་ཡོད་དགག་པ་དང་། བརྟེན་ནས་བརྟགས་པ་ཙམ་དུ་བཞག་པ་དཔེ་དང་བཅས་པར་བཤད་པ་དང་། དེ་ལྟར་བཞག་པ་ལ་མཐར་འཛིན་རྟོག་པ་སྤངས་སླ་བའི་ཡོན་ཏན་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། ཕྱོགས་སྔ་མ་བརྗོད་པ་དང་། ལུགས་དེ་དགག་པ་དང་།
Enumeration Block 5:
འདི་ལ་གཉིས། གྲངས་ཅན་གྱི་ལུགས་བརྗོད་པ་དང་། བྱེ་བྲག་པ་ལ་སོགས་པའི་ལུགས་བརྗོད་པའོ།
Enumeration Block 6:
རང་སྡེས་བཏགས་པའི་ཕུང་བོ་ཉིད་བདག་ཏུ་འདོད་པ་བཀག་པ་ལ་ལྔ་སྟེ། ཕུང་བོ་བདག་ཏུ་འདོད་པ་ལ་གནོད་བྱེད་བསྟན་པ། དེ་ལྟར་འདོད་པ་ལ་མི་རིགས་པའི་སྒྲུབ་བྱེད་བསྟན་པ། ཕུང་པོ་བདག་ཏུ་སྨྲ་བ་ལ་གནོད་བྱེད་གཞན་བསྟན་པ། ཕུང་བོ་བདག་ཏུ་གསུངས་པ་སོགས་ཀྱི་དགོངས་པ་བཤད་པ། གཞན་གྱི་ལུགས་འབྲེལ་མེད་དུ་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང་། སྐྱོན་སྤོང་གི་ལན་དགག་པའོ། །དང་པོ་ལ་གཉིས། ཕྱོགས་སྔ་མ་བརྗོད་པ་དང་། ལུགས་དེ་དགག་པའོ། །
Enumeration Block 7:
ཕུང་པོ་བདག་ཏུ་གསུངས་པ་སོགས་ཀྱི་དགོགས་པ་བཤད་པ་ལ་ལྔ། བདག་ཏུ་ལྟ་བ་ཐམས་ཅད་ཕུང་པོ་ཁོ་ན་ལ་ལྟ་བར་གསུངས་པའི་དོན་བཤད་པ་དང་། མདོ་གཞན་ལ་བརྟེན་ནས་ཕུང་པོའི་ཚོགས་པ་ཙམ་བདག་མིན་པར་བཤད་པ་དང་། ཕུང་པོའི་ཚོགས་པ་ཙམ་གྱིས་དབྱིབས་ཀྱི་བཀོད་པ་བདག་ཡིན་པ་དགག་པ་དང་། ཕུང་པོའི་ཚོགས་ཙམ་བདག་ཏུ་འདོད་པ་ལ་གནོད་བྱེད་གཞན་བསྟན་པ་དང་། ཐུབ་པས་བདག་དེ་ཁམས་དྲུག་ལ་སོགས་པ་ལ་རྟེན་ནས་བརྟགས་པར་གསུངས་པའོ། །དང་བོ་ལ་གསུམ། ལུང་གི་དགོངས་པ་དགག་བྱ་གཅོད་པའི་དགག་ཕྱོགས་ནས་ཡིན་པར་བསྟན་པ། སྒྲུབ་ཕྱོགས་ནས་ཡིན་དུ་ཆུག་ཀྱང་ཕུང་པོ་བདག་ཏུ་སྟོན་པ་མིན་པ། དེ་དག་ལ་གཞན་གྱི་རྩོད་པ་སྤོང་བའོ། །
