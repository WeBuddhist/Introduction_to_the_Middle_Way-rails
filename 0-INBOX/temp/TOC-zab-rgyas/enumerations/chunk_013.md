Enumeration Block 1:
ས་གཉིས་པ་དྲི་མ་མེད་བཤད་པ་ལ། ཚིག་དོན་དང་མཐའ་དཔྱད་པ་གཉིས། དང་པོ་ལ་ལྔ་སྟེ། ས་འདིར་ཚུལ་ཁྲིམས་ཡོངས་སུ་དག་པ་བསྟན་པ། ཚུལ་ཁྲིམས་ཀྱི་བསྔགས་པ་བསྟན་པ་དང་། ཚུལ་ཁྲིམས་ཀྱི་མི་མཐུན་ཕྱོགས་དག་མ་འདྲེས་པའི་དཔེ་བསྟན་པ་དང་། ཚུལ་ཁྲིམས་ཀྱི་ཕར་ཕྱིན་གྱི་དབྱེ་བ་བསྟན་པ་དང་། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུ་པའོ། །དང་པོ་ལ་བཞི། ས་འདིར་ཚུལ་ཁྲིམས་ཕུན་སུམ་ཚོགས་པ་བསྟན་པ། དེ་ལ་བརྟེན་ཡོན་ཏན་ཡོངས་སུ་དག་པར་བསྟན་པ། ས་དང་པོ་ལས་ཚུལ་ཁྲིམས་ལྷག་པར་བསྟན་པ། ཚུལ་ཁྲིམས་ཡོངས་སུ་དག་པའི་རྒྱུ་གཞན་བསྟན་པའོ། །
Enumeration Block 2:
ས་འདིར་ཚུལ་ཁྲིམས་ཀྱི་བསྔགས་པ་བསྟན་པ་ལ། སྦྱིན་འབྲས་བདེ་འགྲོར་སྤྱོད་པ་ཚུལ་ཁྲིམས་ལ་རགས་ལས་པ། སྦྱིན་འབྲས་སྐྱེ་བ་བརྒྱུད་མར་སྤྱོད་པ་ཚུལ་ཁྲིམས་ལ་རག་ལས་པ། ཚུལ་ཁྲིམས་དང་བྲལ་ངན་འགྲོ་ལས་ཐར་བ་ཤིན་ཏུ་དཀའ་བར་བསྟན་པ། སྦྱིན་པའི་གཏམ་གྱི་རྗེས་སུ་ཚུལ་ཁྲིམས་ཀྱི་གཏམ་མཛད་པའི་རྒྱུ་མཚན། མངོན་མཐོ་དང་ངེས་ལེགས་གཉིས་ཀའི་རྒྱུར་ཚུལ་ཁྲིམས་བསྔགས་པ་དང་ལྔའོ། །
Enumeration Block 3:
མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤངས་གསུམ་ལས།
Enumeration Block 4:
ས་གསུམ་པ་འོད་བྱེད་པ་བཤད་པ་ལ་བཞི། ཁྱད་གཞི་སའི་ངེས་ཚིག་ཁྱད་ཆོས་སའི་ཡོན་ཏན། ཕར་ཕྱིན་དང་པོ་གསུམ་གྱི་ཁྱད་པར་གྱི་ཆོས། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུས་པའོ། །
Enumeration Block 5:
ཁྱད་ཆོས་སའི་ཡོན་ཏན་བཤད་པ་ལ་བཞི། ས་འདིར་བཟོད་པ་ལྷག་པར་བསྟན་པ། བཟོད་པ་གཞན་ཇི་ལྟར་བསྟེན་པའི་ཚུལ། བཟོད་པའི་ཕར་ཕྱིན་གྱི་དབྱེ་བ། ས་འདིར་འབྱུང་བའི་དག་པའི་ཡོན་ཏན་གཞན་བསྟན་པའོ། །
Enumeration Block 6:
བཟོད་པ་གཞན་ཇི་ལྟར་འདྲེན་པའི་ཚུལ་གཉིས། ཁོང་ཁྲོ་བྱ་བར་མི་རིགས་པ་དང་། བཟོད་པ་བསྟེན་པར་རིགས་པའོ། །དང་པོ་ལ་བཞི། དགོས་པ་མེད་ཅིང་ཉེས་དམིགས་ཆེ་བའི་ཁོང་ཁྲོ་བར་མི་རིགས་པ་དང་། ཕྱིས་ཀྱི་སྡུག་བསྔལ་མི་འདོད་པ་དང་གནོད་ལན་བྱེད་པ་གཉིས་འགལ་བར་བསྟན་པ། སྔར་ཡུན་རིང་བསགས་པའི་དགེ་བ་འཇོམས་པས་ཁོང་ཁྲོ་བར་མི་རིགས་པ། མི་བཟོད་པའི་སྐྱོན་མང་པོ་བསམ་ནས་ཁོང་ཁྲོ་དགག་པའོ། །

ཚིག་དོན་མཐའ་དཔྱད་གཉིས།
Enumeration Block 8:
མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
