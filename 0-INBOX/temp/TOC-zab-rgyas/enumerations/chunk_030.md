Enumeration Block 1:
ལྔ་པ་ཕྱེ་བ་སོ་སོའི་དོན་བཤད་པ་ལ། མཚན་ཉིད། དབྱེ་བ། སྒྲ་བཤད་གསུམ། དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
ཀུན་རྫོབ་བདེན་པ་ལ་སྒྲས་བརྗོད་རིགས་ཀྱི་སྒོ་ནས་དབྱེ་ན། འཇིག་རྟེན་ཤེས་ངོ་ལ་ལྟོས་ཏེ་ཡང་དག་དང་། དེ་ལ་ལྟོས་ཏེ་ལོག་པ་གཉིས།
Enumeration Block 3:
དོན་དམ་བདེན་པ་ལ་སྒྲས་བརྗོད་རིགས་ཀྱི་དབྱེ་བ། ཡུལ་ཅན་དོན་དམ་དང་། ཡུལ་དོན་དམ་གཉིས་ཡོད། དང་པོ་ལ། ཡུལ་ཅན་གྱི་དོན་དམ་དངོས་དང་། ཡུལ་ཅན་གྱི་དོན་དམ་རྗེས་མཐུན་པའི་དོན་དམ་གཉིས་ཡོད།
Enumeration Block 4:
གཉིས་པ་ཡུལ་གྱི་དོན་དམ་པ་ལ། ཡུལ་གྱི་དོན་དམ་པ་དངོས་དང་། ཡུལ་གྱི་མཐུན་པའི་དོན་དམ་པ་གཉིས།
Enumeration Block 5:
ཀུན་རྫོབ་ཀྱི་སྒྲ་དོན་ལ་གསུམ་དང་། བདེན་པའི་སྒྲ་དོན་གཉིས་སོ་སོར་ཡོད་ལ།
