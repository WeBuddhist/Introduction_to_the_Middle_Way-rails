Enumeration Block 1:
དབུ་མ་ལ་འཇུག་པ་རྩ་འགྲེལ་དང་བཅས་པའི་དགོངས་དོན་ཕྱོགས་གཅིག་ཏུ་འཆད་པ་ལ་བཞི། མཚན་གྱི་དོན། འགྱུར་གྱི་ཕྱག གཞུང་གི་དོན། མཇུག་གི་དོན། དང་པོ་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་འགྱུར་ཕྱག་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་གཉིས།
Enumeration Block 4:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་གཞུང་གི་དོན་འཆད་པ་ལ་བཞི། བསྟན་བཅོས་རྩོམ་པ་ལ་འཇུག་པའི་ཐབས་མཆོད་པར་བརྗོད་པ། བརྩམས་པའི་བསྟན་བཅོས་ཀྱི་ལུས་དངོས། བསྟན་བཅོས་ཇི་ལྟར་བརྩམས་པའི་ཚུལ། བསྟན་བཅོས་བརྩམས་པའི་དགེ་བ་བསྔོ་བའོ། །དང་པོ་ལ་སྙིང་རྗེ་ཆེན་པོ་ལ་སོ་སོར་མ་ཕྱེ་བར་བསྟོད་པ་དང་། སྙིང་རྗེ་ཆེན་པོ་ལ་སོ་སོར་ཕྱེ་སྟེ་ཕྱག་འཚལ་བའོ། །
Enumeration Block 6:
སྙིང་རྗེ་བྱང་སེམས་ཀྱི་གཙོ་བོའི་རྒྱུར་བསྟན་པ་དང་། བྱང་སེམས་ཀྱི་རྒྱུ་གཞན་གཉིས་ཀྱི་ཡང་རྩ་བར་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། ཉན་རང་གཉིས་ཐུབ་དབང་ལས་སྐྱེས་ཚུལ་དང་། སངས་རྒྱས་བྱང་སེམས་ལས་འཁྲུངས་ཚུལ་དང་། བྱང་ཆུབ་སེམས་དཔའི་རྒྱུའི་གཙོ་བོ་གསུམ་བསྟན་པའོ། །དང་པོ་གཞུང་དོན་དང་མཐའ་དཔྱད་པ་གཉིས། དང་པོ་ལ། ཐུབ་དབང་གི་དོན་དང་། ཉན་ཐོས་ཀྱི་དོན་དང་། རང་རྒྱལ་གྱི་དོན་དང་། ཐུབ་དབང་ལས་དེ་གཉིས་སྐྱེ་ཚུལ་དང་བཞི།
Enumeration Block 7:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
