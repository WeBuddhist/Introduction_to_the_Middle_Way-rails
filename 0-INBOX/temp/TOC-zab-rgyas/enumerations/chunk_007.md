Enumeration Block 1:
གསུམ་པ་དེ་དག་གི་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་གཞན་གྱི་རྒྱུད་ཟིལ་གྱིས་གནོན་པའི་ཡོན་ཏན་ལ། ས་འདིར་ཉན་རང་རྣམས་རིགས་ཀྱི་སྒོ་ནས་ཟིལ་གྱིས་གནོན་བ་དང་། ས་བདུན་པར་ཉན་རང་རྣམས་བློ་སྟོབས་ཀྱིས་ཟིལ་གྱིས་གནོན་པ་དང་། དེའི་གྲུབ་དོན་འཕྲོས་དང་བཅས་པ་དང་གསུམ། དང་པོ་ལ། ཚིག་དོན་དང་དཔྱད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ས་བདུན་པར་ཉན་རང་བློའི་སྟོབས་ཀྱིས་ཟིལ་གྱིས་གནོན་པ་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
