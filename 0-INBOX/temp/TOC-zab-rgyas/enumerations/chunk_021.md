Enumeration Block 1:
༈གཉིས་པ་ལུང་གི་དོན་རིགས་པས་སྒྲུབ་པ་ལ་གཉིས། ཆོས་ཀྱི་བདག་མེད་རིགས་པས་སྒྲུབ་པ་དང་། གང་ཟག་གི་བདག་མེད་རིགས་པས་བསྒྲུབ་པའོ། །དང་པོ་ལ། མཐའ་བཞིའི་སྐྱེ་བ་བདེན་པ་གཉིས་ཆར་དུ་དགག་པ། དེ་ལྟར་བཀག་པ་ལ་རྩོད་པ་སྤོང་བ་དང་། རྟེན་འབྱུང་གི་སྐྱེ་བ་ཉིད་ཀྱིས་མཐར་འཛིན་གྱི་ལོག་རྟོག་འགོག་ཚུལ། རིགས་པས་དཔྱད་པ་བྱས་པའི་འབྲས་བུ་ངོས་བཟུང་བ་དང་བཞི།
Enumeration Block 2:
དང་པོ་དུ་མ་ཡོད་དེ། གཞན་གྲགས་ཀྱི་རྗེས་དཔག་སྐྱེད་བྱེད་ཀྱི་ཐལ་འགྱུར། རྒྱུ་མཚན་མཚུངས་པ་ལ་མགོ་སྙོམས་ཀྱི་ཐལ་འགྱུར། འགལ་བརྗོད་ཀྱི་ཐལ་འགྱུར། འགལ་བརྗོད་དང་འདོད་པ་སྒྲུབ་པའི་ཐལ་འགྱུར། སྒྲུབ་བྱེད་བསྒྲུབ་བྱ་དང་མཚུངས་པའི་ཐལ་འགྱུར་དང་ལྔ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
རྡོ་རྗེ་གཟེགས་མའི་གཏན་ཚིགས་དང་། འབྲས་བུ་ལ་དཔྱོད་པ་ཡོད་མེད་སྐྱེ་འགོག་གི་གཏན་ཚིགས་དང་། རྒྱུ་འབྲས་གཉིས་ཀ་ལ་དཔྱོད་པ་མུ་བཞི་སྐྱེ་འགོག་གི་གཏན་ཚིགས་དང་། ཆོས་རྣམས་ཀྱི་ངོ་བོ་རྒྱུ་འབྲས་གསུམ་ལ་དཔྱོད་པ་རིགས་པའི་རྒྱལ་པོ་རྟེན་འབྲེལ་གྱི་གཏན་ཚིགས་དང་ལྔ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
དེ་ལྟར་དམ་བཅས་པའི་དོན་དེ་འཆད་པ་ལ། རང་བཞིན་གྱིས་སྐྱེ་བ་མིན་པའི་དམ་བཅའ་བཞག་པ་དང་། དེ་རིགས་པས་སྒྲུབ་བྱེད་བསྟན་པ་དང་། མཐའ་བཞིའི་སྐྱེ་བ་བཀག་པས་གྲུབ་པའི་དོན་དང་གསུམ་མོ། །
Enumeration Block 5:
གཉིས་པ་དེ་རིགས་པས་སྒྲུབ་པའི་སྒྲུབ་བྱེད་བསྟན་པ་ལ་བཞི། བདག་སྐྱེ་དགག་པ། གཞན་སྐྱེ་དགག་པ། གཉིས་ཀ་ལས་སྐྱེ་བ་དགག་པ། རྒྱུ་མེད་པར་སྐྱེ་བ་དགག་པའོ། །དང་པོ་ལ། ཚིག་དོན་དང་། སྤྱི་དོན་དང་། མཐའ་དཔྱད་པའོ། །དང་པོ་ལ་གཉིས་སྟེ། འགྲེལ་བའི་རིགས་པས་དགག་པ་དང་། རྩ་ཤེས་ཀྱི་རིགས་པས་དགག་པའོ། །དང་པོ་ལ་གསུམ། དེ་ཁོ་ན་ཉིད་རྟོགས་པར་འདོད་པའི་གྲུབ་མཐའ་མཁན་གྱི་ལུགས་དགག་པ། གྲུབ་མཐས་བློ་མ་བསྒྱུར་བའི་ཐ་སྙད་དུ་ཡང་མེད་པར་བསྟན་པ། དེ་ལྟར་བཀག་པ་རྣམས་ཀྱི་དོན་བསྡུས་པའོ། །དང་པོ་ལ་གཉིས། རང་དང་ངོ་བོ་གཅིག་པའི་རྒྱུ་ལས་སྐྱེ་བ་དགག་པ། རྒྱུ་དང་འབྲས་བུ་གཉིས་ངོ་བོ་གཅིག་པ་དགག་པའོ། །དང་པོ་ལ་གསུམ། ངོ་བོ་གཅིག་པའི་རྒྱུ་ལས་སྐྱེ་བ་དོན་མེད་དུ་ཐལ་བ་དང་། ངོ་བོ་གཅིག་པ་ལས་སྐྱེ་ན་རིགས་པ་དང་འགལ་བ་དང་། དེ་དག་གི་ཉེས་སྤོང་གི་ལན་དགག་པའོ། །
Enumeration Block 6:
