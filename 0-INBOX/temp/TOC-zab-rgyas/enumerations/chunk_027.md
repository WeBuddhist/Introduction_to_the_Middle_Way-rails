Enumeration Block 1:
གཉིས་པ་གཞན་སྐྱེ་དགག་པ་ལ། གཞན་སྐྱེ་འདོད་པའི་ཕྱོགས་སྤྱིར་དགག་པོ་དང་། སེམས་ཙམ་པའི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་གཉིས། དང་བོ་ལ་ལྔ་སྟེ་གཞན་སྐྱེ་དགག་པ་དངོས། དགག་པ་ལ་འཇིག་རྟེན་གྱི་རྩོད་པ་སྤང་བ། དེ་ལྟར་བཀག་པའི་ཡོན་ཏན་བསྟན་པ། རང་བཞིན་གྱིས་སྐྱེ་བ་འགར་ཡང་མེད་པར་བསྟན་པ། བདེན་པ་གཉིས་ཆར་དུ་ཡང་རང་བཞིན་གྱིས་སྐྱེ་བ་བཀག་པའི་ཡོན་ཏན་བསྟན་པའོ། །དང་བོ་ལ་ཚིག་དོན་དང་མཐའ་དཔྱད་པ་གཉིས། དང་བོ་ལ་གསུམ། གཞན་སྐྱེ་སྤྱིར་དགག་པ། གཞན་སྐྱེ་བྱེ་བྲག་ཏུ་དགག་པ། འབྲས་བུ་ལ་མུ་བཞིར་དཔྱད་ནས་གཞན་སྐྱེ་དགག་པ་གསུམ། དང་བོ་ལ་གཉིས། ཧ་ཅང་ཐལ་བའི་དགག་པ། སྐྱོན་སྤོང་གི་ལན་དགག་པའོ། །
Enumeration Block 2:
གཉིས་པ་སྐྱོན་སྤོང་གི་ལན་དགག་པ་ལ། སྐྱོན་སྤོང་གི་ལན་དང་། དེ་དགག་པའོ། །
Enumeration Block 3:
གཉིས་པ་གཞན་སྐྱེ་བྱེ་བྲག་ཏུ་དགག་པ་ལ། རྒྱུ་འབྲས་སྔ་ཕྱི་བ་ལ་གཞན་སྐྱེ་དགག་པ། རྒྱུ་འབྲས་དུས་མཉམ་པ་ལ་གཞན་སྐྱེ་དགག་པའོ། །དང་པོ་ལ་དངོས་ཀྱི་དོན་དང་། བཀག་པ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 4:
གཉིས་པ་གཞན་སྐྱེ་དགག་པ་ལ་འཇིག་རྟེན་གྱི་གནོད་པ་སྤང་བ་ལ། འཇིག་རྟེན་གྱི་གྲགས་པའི་གཞན་སྐྱེ་ཁས་བླངས་ནས་འཇིག་རྟེན་གྱི་གནོད་པ་སྤང་བ། འཇིག་རྟེན་གྱི་ཐ་སྙད་དུ་ཡང་གཞན་སྐྱེ་མེད་པས་འཇིག་རྟེན་གྱི་གནོད་པ་སྤང་བ་དང་། དང་པོ་ལ། འཇིག་རྟེན་གྱིས་གནོད་པའི་རྩོད་པ་དང་། དེས་མི་གནོད་པའི་ལན་བསྟན་པའོ། །
Enumeration Block 5:
བདེན་གཉིས་བསྟན་པ་ལ་ལྔ། བདེན་གཉིས་སྤྱིའི་རྣམ་བཞག་དང་། སྐབས་ཀྱི་དོན་ལ་སྦྱར་བ་དང་། བདེན་གཉིས་སོ་སོའི་ངོ་བོ་དང་། དེ་བཀག་པ་ལ་གནོད་པར་འདོད་པ་ལ་གནོད་བྱེད་བསྟན་པ་དང་། འཇིག་རྟེན་པའི་གནོད་ཚུལ་དང་ལྔའོ། །དང་པོ་ལ་གསུམ། བདེན་པ་གཉིས་སུ་དབྱེ་བས་ཆོས་རྣམས་ལ་ངོ་བོ་གཉིས་གཉིས་ཡོད་པར་བརྗོད་པ། འཇིག་རྟེན་ལ་ལྟོས་ཏེ་ཀུན་རྫོབ་ཀྱི་དབྱེ་བ་བཤད་པ། ཞེན་ཡུལ་ལ་འཁྲུལ་བའི་ཡུལ་ཐ་སྙད་དུ་མེད་པར་བསྟན་པའོ། །
Enumeration Block 6:
གསུམ་པ་བདེན་གཉིས་སོ་སོའི་ངོ་བོ་བཤད་པ་ལ་གཉིས། སྤྱི་དོན་གྱི་སྒོ་ནས་མཐའ་དཔྱད་པ་དང་། བདེན་གཉིས་ཀྱི་གཞུང་གི་དོན་བཤད་པའོ། །དང་པོ་ལ། དགག་བཞག་སྤང་གསུམ་ལས། དང་པོ་ལ། བདེན་པ་གཉིས་ཀྱི་དབྱེ་གཞི་ལ་དཔྱད་པ། དབྱེ་བའི་ངོ་བོ་ལ་དཔྱད་པ། གཅིག་དང་ཐ་དད་ལ་དཔྱད་པ། སོ་སོའི་ངོ་བོ་ལ་དཔྱད་པ། སྒྲ་དོན་ལ་དཔྱད་པ་དང་ལྔ།
