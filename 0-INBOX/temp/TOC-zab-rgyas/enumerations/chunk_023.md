Enumeration Block 1:
སྐྱོན་དེ་སངས་རྒྱས་བསྐྱངས་ལ་མི་འཇུག་པར་ཟླ་བས་བཤད་ཚུལ་ལ། སྐྱོན་གསུམ་མི་འཇུག་པའི་ཚུལ་དང་། ལེགས་ལྡན་གྱི་ལུགས་བཀག་པ་གཉིས། དང་པོ་ལ། གཏན་ཚིགས་སོགས་མ་བརྗོད་པ་དང་གཞན་གྱི་སྨྲས་པའི་སྐྱོན་གཉིས་མི་འཇུག་པའི་ཚུལ་དང་། གསུམ་པ་གྲུབ་མཐའ་དང་འགལ་བའི་སྐྱོན་མི་འཇུག་པའི་ཚུལ་གཉིས། དང་པོ་ལ་རང་རྒྱུད་ཀྱི་དབང་དུ་བྱས་པའི་སྐྱོན་མེད་ཚུལ་དང་། གཞན་གྲགས་ཀྱི་དབང་དུ་བྱས་པའི་སྐྱོན་མེད་ཚུལ་གཉིས། དང་པོ་ལ་རང་རྒྱུད་མ་བཀོད་པའི་ཚུལ་དང་། རང་རྒྱུད་ལ་གཞན་གྱིས་སྨྲས་པའི་ཉེས་པ་སེལ་མི་དགོས་པའི་ཚུལ། དང་པོ་ལ་རང་རྒྱུད་ལ་དགོས་པ་མེད་པ་དང་། རང་རྒྱུད་ལ་ནུས་པ་མེད་པ་དང་། རང་རྒྱུད་ཁས་ལེན་མི་རིགས་པ་གསུམ།
Enumeration Block 2:
གཞན་གྲགས་ཀྱི་དབང་དུ་བྱས་པའི་སྐྱོན་མེད་ཚུལ་ལ། རྩོད་པ་དང་། ལན་གཉིས།
Enumeration Block 3:
ལན་ལ། སངས་རྒྱས་བསྐྱངས་ཀྱིས་སྦྱོར་བ་དེས་གཞན་གྲགས་ཀྱི་རྟགས་དཔེ་མ་བརྗོད་པས་སྐྱོན་མེད་ཚུལ་དང་། དེ་ལ་སྨྲས་པའི་ཉེས་པ་མ་བསལ་བའི་སྐྱོན་མེད་ཚུལ་གཉིས། དང་པོ་ལ། སྐབས་འདིར་གཞན་གྲགས་གཙོ་བོར་བྱས་ནས་མ་བཤད་པའི་རྒྱུ་མཚན་དང་། རྒོལ་བ་འགའ་ལ་གཞན་གྲགས་བརྗོད་དགོས་ནའང་སྐབས་འདིར་དེ་བརྗོད་པར་བཤད་པ་གཉིས།
Enumeration Block 4:
ཕྱི་རྒོལ་འགའ་ཞིག་ལ་གཞན་གྲགས་བརྗོད་དགོ་ནའང་བརྗོད་པར་བསྟན་པ་ལ། རྩོད་པ་དང་། ལན་གཉིས།
Enumeration Block 5:
ལེགས་ལྡན་གྱི་ལུགས་དགག་པ་ལ། རང་རྒྱུད་འགོག་པའི་རིགས་པ་མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས།
Enumeration Block 6:
རང་རྒྱུད་འགོག་པའི་རིགས་པ་རྒྱས་པར་བཤད་པ་ལ། ཕྱོགས་སོགས་མ་གྲུབ་པས་བདག་སྐྱེ་འགོག་པའི་རང་རྒྱུད་འགོག་པ་དང་། བདག་སྐྱེ་འགོག་པའི་རྟགས་མ་གྲུབ་པར་ཐལ་བར་ལེགས་ལྡན་གྱི་ཁས་བླངས་ཚུལ་དང་། རང་རྒྱུད་ཀྱི་སྦྱོར་བ་གཞན་ལ་མ་གྲུབ་པའི་སྐྱོན་དང་། དེ་གཞན་ལ་མ་ངེས་པའི་སྐྱོན་དང་། སྐྱོན་དེ་རང་གི་གཞན་གྲགས་ལ་མི་འཇུག་པའི་རྒྱུ་མཚན་དང་ལྔ་ལས། དང་པོ་། དོན་དམ་པའི་ཁྱད་པར་སྦྱོར་བ་དོན་མེད་པར་བཤད་པ་དང་། ཆོས་ཅན་སྤྱི་ཙམ་འཛིན་པའི་ལན་དགག་པ་གཉིས། དང་པོ་ལ། ཆོས་ཀྱི་ཁྱད་པར་ལ་སྦྱར་དགོས་པ་དགག་པ། ཆོས་ཅན་གྱི་ཁྱད་པར་ལ་སྦྱར་དགོས་པ་དགག་པ་གཉིས། དང་པོ་ལ། དྲི་བ་དང་། ལན་དགག་པ་གཉིས།
