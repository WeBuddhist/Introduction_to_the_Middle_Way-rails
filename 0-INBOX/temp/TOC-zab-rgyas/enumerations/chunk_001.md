Enumeration Block 1:
གཉིས་པ་མཐའ་དཔྱད་པ་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་སངས་རྒྱས་རྣམས་བྱང་སེམས་ལས་འཁྲུངས་ཚུལ་བསྟན་པ་ལ། ཚིག་དོན་དང་། འགྲེལ་བའི་སྤྱི་དོན་དང་། མཐའ་དཔྱད་པ་གསུམ།
Enumeration Block 3:
གཉིས་པ་འགྲེལ་བའི་སྤྱི་དོན་ལ། འགྲེལ་བའི་གཞུང་འགོད་པ་དང་། དོན་བཤད་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་དོན་བཤད་པ་ལ་རྩོད་པ་དང་། ལན་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལན་ལ་གཉིས། རིགས་པས་སྒྲུབ་པ་དང་ལུང་གི་སྒྲུབ་པ་གཉིས།
