Enumeration Block 1:
གཉིས་པ་ལ། རྒྱས་པར་བཅུ་དྲུག་ཏུ་དབྱེ་བ་དང་། བསྡུས་ཏེ་བཞིར་དབྱེ་བ་གཉིས། དང་པོ་ལ། ནང་སྟོང་པ་ཉིད་སོགས་བཞི་བཤད་པ་དང་། ཆེན་པོ་སྟོང་པ་ཉིད་སོགས་བཞི་དང་། མཐའ་ལས་འདས་པ་སྟོང་པ་ཉིད་སོགས་བཞི། ཆོས་ཐམས་ཅད་སྟོང་པ་ཉིད་སོགས་བཞི་བཤད་པ་དང་བཞིའོ། །དང་པོ། ནང་སྟོང་པ་ཉིད། ཕྱི་སྟོང་པ་ཉིད། ཕྱི་ནང་སྟོང་པ་ཉིད། སྟོང་པ་ཉིད་སྟོང་པ་ཉིད་དང་བཞི་ལས།
Enumeration Block 2:
གཉིས་པ་ལ། ཆེན་པོ། དོན་དམ་པ། འདུས་བྱས། འདུས་མ་བྱས་སྟོང་པ་ཉིད་དང་བཞི་ལས།
Enumeration Block 3:
གསུམ་པ་ལ། མཐའ་ལས་འདས་སྟོང་། ཐོག་མ་དང་ཐ་མ་མེད་སྟོང་། དོར་བ་མེད་སྟོང་། རང་བཞིན་སྟོང་པ་ཉིད་བཞི་ལས།
Enumeration Block 4:
བཞི་པ་ལ། ཆོས་ཐམས་ཅད་སྟོང་པ་ཉིད་དང་། རང་གི་མཚན་ཉིད་སྟོང་པ་ཉིད་དང་། དམིགས་པ་མེད་པ་སྟོང་ཉིད་དང་། ངོ་བོ་མེད་པའི་ངོ་བོ་ཉིད་སྟོང་པ་ཉིད་བཞི་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་བསྟན་བཤད་བསྡུ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ། གཞི་ཡི་ཆོས་ཀྱི་རང་མཚན། ལམ་གྱི་ཆོས་ཀྱི་རང་མཚན། འབྲས་བུའི་ཆོས་ཀྱི་རང་མཚན་གསུམ།
Enumeration Block 7:
གཉིས་པ་ལ། དབྱེ་བ་དངོས་དང་། ཞར་བྱུང་སྟོང་ཉིད་ཉི་ཤུ་པོའི་མཇུག་བསྡུ་བ་གཉིས། དང་པོ་ལ། དངོས་པོ་སྟོང་པ། དངོས་མེད་སྟོང་པ། རང་གི་ངོ་བོས་སྟོང་པ། གཞན་གྱི་ངོ་བོས་སྟོང་པ་བཞི།
Enumeration Block 8:
གསུམ་པ་རིང་དུ་སོང་བ་སོགས་བཞི་བཤད་པ་ལ། ས་བདུན་པ་རིང་དུ་སོང་བ། བརྒྱད་པ་མི་གཡོ་བ། དགུ་པ་ལེགས་པའི་བློ་གྲོས། བཅུ་པ་ཆོས་ཀྱི་སྤྲིན་བཤད་པ་བཞི།
Enumeration Block 9:
གཉིས་པ་ལ། ས་བརྒྱད་པ་ཐོབ་ཚུལ། ས་དེར་སྨོན་ལམ་གྱི་ཕར་ཕྱིན་ལྷག་ཚུལ། ས་དེའི་ཡོན་ཏན་གྱི་ཁྱད་པར་བསྟན་པ་དང་གསུམ།
Enumeration Block 10:
གསུམ་པ་ལ། སྲིད་པ་འགགས་པའི་ཡོན་ཏན་དང་། འགགས་ཀྱང་སྲིད་པར་སྤྲུལ་པ་སྟོན་པའི་ཡོན་ཏན་གཉིས། དང་པོ་ལ། སྲིད་པར་མཚམས་སྦྱོར་བ་ཡོངས་སུ་སྤངས་ཀྱང་སྲིད་པར་རྣམ་རོལ་སྟོན་པའི་ཆོས་ཐོབ་པར་དེ་བཞིན་གཤེགས་པས་བསྐུལ་བ་དང་། དྲི་མ་ཡོངས་སུ་སྤང་བའི་ཡོན་ཏན་གཉིས།
Enumeration Block 11:
བཞི་པ་ས་བཅུ་པ་ལ། ས་དེའི་ཁྱད་པར་གྱི་ཡོན་ཏན། ཡེ་ཤེས་ཀྱི་ཕར་ཕྱིན་དག་ཚུལ། སའི་ངེས་ཚིག་དང་མཐུན་པའི་ཡོན་ཏན་གསུམ།
Enumeration Block 12:
གཉིས་པ་སའི་ཡོན་ཏན་ལ། ས་དང་པོར་བྱུང་བའི་ཡོན་ཏན་བརྒྱ་ཕྲག་བཅུ་གཉིས་པོ་བཤད་པ་དང་། དེས་གཞན་ལ་བསྒྲེ་ཚུལ་གཉིས།
Enumeration Block 13:
གཉིས་པ་ལ་མ་དག་པའི་ས་ལྷག་མ་དྲུག་ལ་གོང་གི་གྲངས་འགྱུར་གྱིས་བསྒྲེ༷་བ་དང་། དག་པ་གསུམ་ལ་རྡུལ་གྲངས་ཀྱིས་བསྒྲེ་བ་གཉིས།
Enumeration Block 14:
གཉིས་པ་ལ། བརྒྱད་པའི་ཡོན་ཏན། དགུ་པའི་ཡོན་ཏན། བཅུ་པའི་ཡོན་ཏན་གསུམ།
Enumeration Block 15:
གསུམ་པ་ལ་ཡོན་ཏན་བཅུ་གཉིས་པོ་བཤད་པ་དང་། ཡོན་ཏན་གཞན་ཡང་བསྟན་པ་གཉིས།
Enumeration Block 16:
གཉིས་པ་མཐར་ཐུག་སངས་རྒྱས་ཀྱི་ས་བཤད་པ་ལ། དང་པོར་བྱང་ཆུབ་བརྙེས་པའི་ཚུལ། ཐོབ་བྱ་བྱང་ཆུབ་ཀྱི་ངོ་བོ། བྱང་ཆུབ་བརྙེས་ནས་སྤྲུལ་པས་གཞན་དོན་མཛད་ཚུལ་གསུམ། དང་པོ་ལ། དངོས་ཀྱི་དོན་དང་། དེ་ལ་རྩོད་པ་སྤངས་པ་གཉིས། དང་པོ་ལ། དུས་ནམ་གྱི་ཚེ། གནས་གང་དུ། ཚུལ་ཇི་ལྟར་བརྙེས་པ་གསུམ།
