Enumeration Block 1:
གཉིས་པ་ཐ་སྙད་དུ་ཡང་རང་བཞིན་གྱིས་སྐྱེ་བ་དགག་པའི་ཕན་ཡོན་ལ། རྟག་ཆད་ཀྱི་ལྟ་བ་ཤིན་ཏུ་ཕྲ་བ་སྤོང་བའི་ཡོན་ཏན་དང་། ལས་འབྲས་ཀྱི་འབྲེལ་པ་ཆེས་འཐད་པའི་ཡོན་ཏན་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ། ཀུན་གཞི་སོགས་མེད་ཀྱང་ལས་འགགས་པ་ལས་འབྲས་བུ་འབྱིན་ནུས་པའི་ཚུལ་དང་། དེ་ལྟར་བསྟན་པ་ལ་རྩོད་པ་སྤང་བ་གཉིས། དང་པོ་ལ་དངོས་དང་། དཔེ་བསྟན་པའོ།
Enumeration Block 3:
གཉིས་པ་རྩོད་སྤོང་ལ། རྣམ་སྨིན་ཐུག་མེད་དུ་འབྱིན་པའི་རྩོད་སྤོང་དང་། ཀུན་གཞི་ཡོད་པར་གསུངས་པའི་ལུང་དང་འགལ་བའི་རྩོད་སྤང་གཉིས། དང་པོ་ལ། དོན་གཉིས་མཚོན་པའི་དཔེ་བསྟན་པ་དང་། དཔེ་ཅན་ལས་ཀྱི་འབྲས་བུ་བསྐྱེད་ཚུལ་དངོས་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། རྣམ་སྨིན་ཐུག་མེད་དུ་མི་འབྱིན་པའི་ཚུལ་དང་། འབྲས་བུ་འཆོལ་བར་མི་འབྱིན་པའི་ཚུལ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལ། ལུང་དེ་འདྲ་བ་དྲང་དོན་དུ་བསྟན་པ་དང་། དེ་དག་གི་དཔེ་བསྟན་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་སེམས་ཙམ་གྱི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་ལ། ཕྱོགས་སྔ་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ། རིགས་པས་དགག་པ་དང་། སེམས་ཙམ་དུ་གསུང་པའི་ལུང་གི་དགོངས་དོན་བཤད་པ་གཉིས། དང་པོ་ལ། ཕྱི་རོལ་མེད་པ་ཤེས་པ་རང་བཞིན་གྱིས་གྲུབ་པ་དགག་པ་དང་། གཞན་དབང་རང་བཞིན་གྱིས་གྲུབ་པ་དགག་པ་གཉིས། དང་པོ་ལ། ཕྱི་རོལ་མེད་པའི་ཤེས་པ་རང་གི་ངོ་བོ་དགག་པ་དང་། དེ་ལས་བེམ་པོར་སྣང་བའི་བག་ཆགས་སྨིན་པའི་ཚུལ་བཤད་པ་དགག་པ། དེ་ལྟར་བཀག་པའི་མཇུག་བསྡུ་བ་གསུམ། དང་པོ་ལ། ཕྱི་རོལ་མེད་པར་ཤེས་པ་རང་བཞིན་གྱིས་གྲུབ་པའི་དཔེ་དགག་པ། བག་ཆགས་ཀྱི་ནུས་པ་ལས་དོན་གྱིས་སྟོང་པའི་ཤེས་པ་སྐྱེ་བའི་དོན་དགག་པ་གཉིས། དང་པོ་ལ། རྨི་ལམ་གྱི་དཔེ་དགག་པ་དང་། སྐྲ་ཤད་མཐོང་བའི་དཔེ་དགག་པ་གཉིས། དང་པོ་ལ། དྲི་བ་དང་འདོད་པ་དེ་དགག་པ་གཉིས།
Enumeration Block 8:
གཉིས་པ་ལ། རྨི་ལམ་གྱི་དཔེས་ཤེས་པ་རང་བཞིན་གྱིས་ཡོད་པར་མི་འགྲུབ་པར་བསྟན་པ། རྨི་ལམ་གྱི་དཔེས་སད་དུས་ཀྱི་ཕྱི་རོལ་མེད་པ་མི་འགྲུབ་པར་བསྟན་པ། དེ་ཡི་ཕྱིར་ན་རྨི་ལམ་གྱི་དཔེས་དངོས་པོ་ཐམས་ཅད་རྫུན་པར་གྲུབ་ཚུལ་བསྟན་པ་གསུམ།
Enumeration Block 9:
གཉིས་པ་ལ། འདོད་པ་བཀོད་པ་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 10:
གཉིས་པ་དོན་སྟོང་གི་ཤེས་པ་སྐྱེ་ཚུལ་དགག་པ་ལ། མཚམས་སྦྱར་བའི་སྒོ་ནས་གཞན་ལུགས་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 11:
གཉིས་པ་དེ་དགག་པ་ལ། མདོར་བསྟན། རྒྱས་བཤད་གཉིས།
Enumeration Block 12:
གཉིས་པ་ལ། རྣམ་ཤེས་ད་ལྟ་བ་ལ་ནུས་པ་རང་བཞིན་གྱིས་ཡོད་པ་དགག་པ། མ་འོངས་པ་ལ་ནུས་པ་རང་བཞིན་གྱིས་ཡོད་པ་དགག་པ། འདས་པ་ལ་ནུས་པ་རང་བཞིན་གྱིས་ཡོད་པ་དགག་པ་གསུམ།
Enumeration Block 13:
གཉིས་པ་ལ། སྤྱིར་དགག་པ་དང་། སྐྱོན་སྤང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 14:
གསུམ་པ་འདས་པའི་ནུས་པ་དགག་པ་ལ། བཀག་པ་དངོས་དང་། དེའི་ཉེས་སྤོང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 15:
གཉིས་པ་ལ། ལན་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 16:
གཉིས་པ་ཤེས་པ་དེ་ལས་བེམ་པོར་སྣང་བའི་བག་ཆགས་སྨིན་ཚུལ་དགག་པ་ལ། ཕྱོགས་སྔ་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 17:
གཉིས་པ་ལ། བཀག་པ་དངོས་དང་། ཤེས་པ་ལས་དོན་སྣང་སྐྱེ་བའི་སྒྲུབ་བྱེད་ལྷག་མ་རྣམས་ཀྱང་དོན་མེད་པར་བསྟན་པ་གཉིས། དང་པོ་ལ། ཕྱི་རོལ་མེད་པར་ཤེས་པ་ཁོ་ན་དོན་སྣང་གི་རྣམ་པར་སྐྱེ་ན་སད་དུས་སུ་ལོང་བ་ལ་གཟུགས་སྣང་བར་ཐལ་བས་དགག་པ། སད་དུས་སུ་ནུས་པ་མ་སྨིན་པར་འདོད་ན་རྨི་ལམ་གྱི་ཚེ་ཡང་གཟུགས་སྣང་མི་སྐྱེ་བར་ཐལ་བས་དགག་པ། དེས་ན་ཡུལ་དབང་ཤེས་གསུམ་བདེན་རྫུན་མཉམ་པར་བསྟན་པ་གསུམ།
Enumeration Block 18:
གཉིས་པ་སེམས་ཙམ་པའི་སྒྲུབ་བྱེད་གཞན་དོན་མེད་པར་སྟོན་པ་ལ། རིགས་པའི་སྒྲུབ་བྱེད་མེད་པ། ལུང་གི་སྒྲུབ་བྱེད་མེད་པ། དཔེས་སྒྲུབ་བྱེད་མེད་པ་གསུམ།
Enumeration Block 19:
གསུམ་པ་ལ་དཔེ་གཞན་མི་སྡུག་པ་བསྒོམ་པའི་ཡིད་ངོར་ཀེང་རུས་སྣང་བའི་དཔེས་བསྒྲུབ་པ་དང་། ཡི་དྭགས་རྣམས་ཀླུང་ལ་རྣག་ཁྲག་ཏུ་མཐོང་བའི་དཔེས་བསྒྲུབ་པ་དོན་མེད་པར་བསྟན་པ་གཉིས།
