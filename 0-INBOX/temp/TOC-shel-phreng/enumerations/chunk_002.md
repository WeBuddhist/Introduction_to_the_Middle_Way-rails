Enumeration Block 1:
གཉིས་པ་རྒྱུ་འབྲས་ངོ་བོ་གཅིག་པ་དགག་པ་ལ། རྒྱུ་འབྲས་ངོ་བོ་གཅིག་ན་གནས་སྐབས་མི་དམིགས་པར་ཐལ་བར་དགག་པ་དང་། གནས་སྐབས་ཐ་དད་པར་དམིགས་ན་རྒྱུ་འབྲས་ངོ་བོ་མི་གཅིག་པར་ཐལ་བས་དགག་པ་གཉིས། དང་པོ་ལ། རྒྱུ་འབྲས་རྣམ་པར་འགྱུར་བ་མི་འཐད་པ་དང་། དེས་ན་དབྱིབས་སོགས་ཐ་དད་མེད་པར་ཐལ་བས་དགག་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ། གནས་སྐབས་ཐ་དད་ན་ངོ་བོ་གཅིག་ཏུ་མི་འཐད་པ་དངོས་དང་། དེ་ལྟར་འཐད་ན་གནས་སྐབས་གཉིས་སུ་གཉིས་ཀ་འཛིན་མི་འཛིན་མཚུངས་པར་ཐལ་བས་དགག་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ། གཞན་སྐྱེ་དགག་པ་ལ། གཞན་སྐྱེ་འདོད་པ་སྤྱིར་དགག་པ་དང་སེམས་ཙམ་པའི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་གཉིས། དང་པོ་ལ། དེ་ཁོ་ན་ཉིད་དུ་གཞན་སྐྱེ་འདོད་པའི་ལུགས་སྤྱིར་དགག་པ་དང་། ཐ་སྙད་དུ་རང་བཞིན་གྱིས་སྐྱེ་བ་ཡོད་པར་འདོད་པའི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པ་གཉིས། དང་པོ་ལ། གཞན་སྐྱེ་དགག་པ་དངོས། བཀག་པ་ལ་འཇིག་རྟེན་གྱིས་གནོད་པ་སྤངས་པ། དེ་ལྟར་བཀག་པའི་ཡོན་ཏན་བསྟན་པ་གསུམ། དང་པོ་ལ། གཞན་སྐྱེ་སྤྱིར་དགག་པ། གཞན་སྐྱེ་བྱེ་བྲག་ཏུ་དགག་པ། འབྲས་བུ་ལ་མུ་བཞིར་དཔྱད་ནས་དགག་པ་གསུམ། དང་པོ་ལ། ཧ་ཅང་ཐལ་བས་དགག་པ། སྐྱོན་སྤོང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། སྐྱོན་སྤང་གི་ལན་དང་། ལན་དེ་དགག་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་བྱེ་བྲག་ཏུ་དགག་པ་ལ། རྒྱུ་འབྲས་སྔ་ཕྱི་བ་ལ་གཞན་སྐྱེ་དགག་པ། རྒྱུ་འབྲས་དུས་མཉམ་པ་ལ་གཞན་སྐྱེ་དགག་པ་གཉིས། དང་པོ་ལ་བཀག་པ་དངོས་དང་། སྐྱོན་སྤང་གི་ལན་དགག་པ་གཉིས།
Enumeration Block 6:
གཉིས་པ་ལ། ལན་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ། ཕར་ལན་འདི་ལ་དམ་བཅའ། རིགས་པ། འབྲས་བུ་དངོས་མེད་ཀྱང་དེ་སྐྱེ་བའི་བྱ་བ་ཡོད་སྙམ་པ་དགག་པ་གསུམ་རིམ་པར།
Enumeration Block 8:
གཉིས་པ། དེ་ལྟར་བཀག་པ་ལ་འཇིག་རྟེན་གྱིས་གནོད་པ་སྤང་བ་ལ། འཇིག་རྟེན་གྱིས་གནོད་པའི་རྩོད་པ་བཀོད་པ་དང་། དེའི་ལན་བསྟན་པ་གཉིས།
Enumeration Block 9:
གཉིས་པ་ལ། འཇིག་རྟེན་པས་གཞན་སྐྱེ་ཁས་བླངས་ཀྱང་འཇིག་རྟེན་པས་མི་གནོད་པའི་ཚུལ་དང་། འཇིག་རྟེན་ཐ་སྙད་དུ་ཡང་རང་བཞིན་གྱིས་གྲུབ་པའི་གཞན་སྐྱེ་མེད་པས་འཇིག་རྟེན་པས་མི་གནོད་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཡུལ་དང་ཡུལ་ཅན་ཕྱིན་ཅི་མ་ལོག་པ་དང་ལོག་པའི་དབྱེ་བས་བདེན་གཉིས་ཀྱི་རྣམ་གཞག་མདོར་བསྟན་པ། དེ་ཉིད་རྒྱས་པར་བཤད་པ། དེ་དག་གི་ཕྱིར་ན་ཡུལ་གང་ལ་འཇིག་རྟེན་གྱིས་མི་གནོད་པ་དང་གནོད་པའི་ཁྱད་པར་བསྟན་པས་མཇུག་བསྡུ་བ་གསུམ།
Enumeration Block 10:
གཉིས་པ་ལ། ཡུལ་ཅན་ཚད་མའི་སྒོ་ནས་འཇིག་རྟེན་གྱིས་མི་གནོད་པའི་ཚུལ་དང་། ཡུལ་བདེན་གཉིས་ཀྱི་སྒོ་ནས་འཇིག་རྟེན་གྱིས་མི་གནོད་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཐ་སྙད་དཔྱོད་བྱེད་ཀྱི་ཚད་མ་བསྟན་པ་དང་། དེས་དོན་དམ་དཔྱོད་བྱེད་ཀྱི་ཚད་མ་ལ་མི་གནོད་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཡུལ་ཅན་ཚད་མ་དང་ཚད་མིན་གྱི་དབྱེ་བ་དང་། དེས་ཡུལ་འཇལ་ཚུལ་གཉིས།
Enumeration Block 11:
གཉིས་པ་ལ། ཡུལ་ཡང་ལོག་གི་ཁྱད་པར་སྤྱིར་བསྟན་པ་དང་། བྱེ་བྲག་ཏུ་ཞེན་ཡུལ་ལ་འཁྲུལ་བའི་ཞེན་ཡུལ་ཐ་སྙད་དཔྱོད་བྱེད་ཀྱི་ཚད་མ་དེའི་ངོར་ཡང་བདེན་པར་མི་འགྲུབ་པའི་ཚུལ་གཉིས།
Enumeration Block 12:
གཉིས་པ་ལ་ཡུལ་ཕྱིན་ཅི་ལོག་པ་ཀུན་རྫོབ་བདེན་པ་ངེས་ཚིག་གི་སྒོ་ནས་བཤད་པ་དང་། ཕྱིན་ཅི་མ་ལོག་པ་དོན་དམ་བདེན་པ་དཔེའི་སྒོ་ནས་བསྟན་པ་གཉིས།
Enumeration Block 13:
གསུམ་པ། མཇུག་བསྡུ་བ་ལ། དེ་ཁོ་ན་ཉིད་ལ་དཔྱད་པའི་སྐབས་སུ་འཇིག་རྟེན་གྱིས་མི་གནོད་པའི་ཚུལ་དང་། འཇིག་རྟེན་རང་གི་དོན་ལ་འཇིག་རྟེན་གྱིས་གནོད་ཚུལ་གཉིས། དང་པོ་ལ། འཇིག་རྟེན་ཚད་མར་མི་རིགས་པའི་ཚུལ་དང་། དེས་ན་ཚད་མིན་གྱིས་ཚད་མ་ལ་མི་གནོད་པར་བསྟན་པ་གཉིས།
Enumeration Block 14:
གཉིས་པ་ཀུན་རྫོབ་ཙམ་དུའང་རང་བཞིན་གྱིས་སྐྱེ་བ་མེད་པར་སྟོན་པ་ལ། ཀུན་རྫོབ་ཏུ་ཡང་རང་བཞིན་གྱིས་སྐྱེ་བ་བཀག་པ་དང་། དེ་ལྟར་བཀག་པའི་ཕན་ཡོན་གཉིས། དང་པོ་ལ། བཀག་པ་དངོས་དང་། དེ་ལ་རྩོད་པ་སྤང་བ་གཉིས། དང་པོ་ལ། འཕགས་པའི་མཉམ་བཞག་དངོས་པོའི་འཇིག་རྒྱུར་ཐལ་བས་དགག་པ། ཐ་སྙད་བདེན་པ་རིགས་པས་དཔྱད་བཟོད་དུ་ཐལ་བས་དགག་པ། དོན་དམ་པས་སྐྱེ་བ་མི་ཁེགས་པར་ཐལ་བས་དགག་པ་གསུམ་ལས།
