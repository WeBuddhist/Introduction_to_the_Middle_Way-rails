Enumeration Block 1:
གཉིས་པ་སའི་ཡོན་ཏན་ལ། ས་དང་པོར་བྱུང་བའི་ཡོན་ཏན་བརྒྱ་ཕྲག་བཅུ་གཉིས་པོ་བཤད་པ་དང་། དེས་གཞན་ལ་བསྒྲེ་ཚུལ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ་མ་དག་པའི་ས་ལྷག་མ་དྲུག་ལ་གོང་གི་གྲངས་འགྱུར་གྱིས་བསྒྲེ༷་བ་དང་། དག་པ་གསུམ་ལ་རྡུལ་གྲངས་ཀྱིས་བསྒྲེ་བ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། བརྒྱད་པའི་ཡོན་ཏན། དགུ་པའི་ཡོན་ཏན། བཅུ་པའི་ཡོན་ཏན་གསུམ།
Enumeration Block 4:
གསུམ་པ་ལ་ཡོན་ཏན་བཅུ་གཉིས་པོ་བཤད་པ་དང་། ཡོན་ཏན་གཞན་ཡང་བསྟན་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་མཐར་ཐུག་སངས་རྒྱས་ཀྱི་ས་བཤད་པ་ལ། དང་པོར་བྱང་ཆུབ་བརྙེས་པའི་ཚུལ། ཐོབ་བྱ་བྱང་ཆུབ་ཀྱི་ངོ་བོ། བྱང་ཆུབ་བརྙེས་ནས་སྤྲུལ་པས་གཞན་དོན་མཛད་ཚུལ་གསུམ། དང་པོ་ལ། དངོས་ཀྱི་དོན་དང་། དེ་ལ་རྩོད་པ་སྤངས་པ་གཉིས། དང་པོ་ལ། དུས་ནམ་གྱི་ཚེ། གནས་གང་དུ། ཚུལ་ཇི་ལྟར་བརྙེས་པ་གསུམ།
Enumeration Block 6:
གཉིས་པ་ལ། རྩོད་པ་དང་། ལན་གཉིས་དང་པོ་ལ། ཡུལ་སྐྱེ་མེད་རྟོགས་པར་མི་འཐད་པར་རྩོད་པ་དང་། ཡུལ་ཡུལ་ཅན་རོ་གཅིག་ན་ཡུལ་དེ་མཁྱེན་ནས་གཞན་ལ་སྟོན་པར་མི་འཐད་པའི་རྩོད་པ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལན་ལ་ཡུལ་སྐྱེ་མེད་རྟོགས་པར་འཐད་པའི་ལན་དང་། ཡུལ་ཡུལ་ཅན་ཐ་དད་དུ་མི་རྟོགས་ཀྱང་ཆོས་སྟོན་པར་འཐད་པ་གཉིས།
Enumeration Block 8:
གཉིས་པ་ལ་དངོས་དང་། དེའི་དཔེ་འགོད་པ་གཉིས།
Enumeration Block 9:
གཉིས་པ་བརྙེས་བྱ་བྱང་ཆུབ་ཀྱི་ངོ་བོ་ལ། རྟེན་སྐུའི་རྣམ་བཞག་དང་། བརྟེན་པ་ཡོན་ཏན་གྱི་ཁྱད་པར་གཉིས། དང་པོ་ལ། ཆོས་སྐུ། ལོངས་སྐུ། རྒྱུ་མཐུན་པའི་སྐུ་གསུམ་ལས།
Enumeration Block 10:
གསུམ་པ་ལ་སྐུའི་བ་སྤུའི་ཁུང་བུར་རང་གི་སྤྱོད་པ་ཀུན་སྟོན་ཚུལ། གནས་དེར་གཞན་གྱི་སྤྱོད་པ་ཀུན་སྟོན་ཚུལ། བཞེད་པ་ཕུན་ཚོགས་ལ་མངའ་དབང་བསྒྱུར་ཚུལ་གསུམ།
Enumeration Block 11:
གསུམ་པ་ལ་ཡུལ་གྱི་དབང་དུ་བྱས་པ་དང་། དུས་ཀྱི་དབང་དུ་བྱས་པ་གཉིས།
Enumeration Block 12:
གཉིས་པ་ཡོན་ཏན་ལ། ཡོན་ཏན་གྱི་གཙོ་བོ་སྟོབས་བཅུ་བཤད་པ། ཡོན་ཏན་ཀུན་བརྗོད་མི་ནུས་པའི་ཚུལ། ཡོན་ཏན་དེ་དག་ཤེས་པའི་ཕན་ཡོན་གསུམ། དང་པོ་ལ་བསྟན་བཤད་གཉིས།
Enumeration Block 13:
གཉིས་པ་ལ། ཡོན་ཏན་ཀུན་རྫོབ་མི་ནུས་པའི་ཚུལ་དང་། འདིར་ནི་ཅུང་ཟད་བརྗོད་པའང་ལུང་ལ་བརྟེན་ནས་ཡིན་ཚུལ་གཉིས།
Enumeration Block 14:
གསུམ་པ་བྱང་ཆུབ་བརྙེས་ནས་སྤྲུལ་པས་འགྲོ་དོན་མཛད་ཚུལ་ལ། སྟོན་པ་མཆོག་གི་སྤྲུལ་པའི་སྐུའི་རྣམ་ཐར་སྟོན་པ། བསྟན་པ་མཐར་ཐུག་ཐེག་པ་གཅིག་ཏུ་གྲུབ་པ། སྟོན་པ་དེ་ཉིད་མངོན་པར་བྱང་ཆུབ་པ་དང་། བཞུགས་པའི་དུས་ཀྱི་སྒོ་ནས་ཚད་མེད་པར་བསྟན་པ་གསུམ།
Enumeration Block 15:
གཉིས་པ་ལ་མཐར་ཐུག་ཐེག་པ་གཅིག་ཏུ་རིགས་པས་གྲུབ་ཚུལ་བརྗོད་པ་དང་། ཐེག་པ་གསུམ་དུ་བསྟན་པ་དྲང་དོན་དུ་བསྟན་པ་གཉིས།
Enumeration Block 16:
གསུམ་པ་ལ། མངོན་པར་བྱང་ཆུབ་པའི་དབང་དུ་བྱས་པ་དང་། རྟག་ཏུ་སྲིད་པར་བཞུགས་པའི་དབང་དུ་བྱས་པ་གཉིས།
Enumeration Block 17:
གཉིས་པ་ལ། མདོར་བསྟན་རྒྱས་བཤད་གཉིས།
Enumeration Block 18:
གཉིས་པ་ལ། འགྲོ་ལ་ཐུགས་བརྩེ་ཚད་མེད་པ་མངའ་ཚུལ་དང་། དེས་ཡུལ་སྡུག་བསྔལ་ཅན་གྱི་སེམས་ཅན་ཟད་པ་མེད་པས་མྱ་ངན་ལས་མི་འདའ་བའི་ཚུལ་གཉིས།
Enumeration Block 19:
གསུམ་པ་མཇུག་མཐར་ཕྱིན་པའི་བྱ་བ་ལ། ཇི་ལྟར་བརྩམས་པའི་ཚུལ་དང་། དེ་ལྟར་བརྩམས་པའི་དགེ་བ་བསྔོ་བ་གཉིས། དང་པོ་ལ། རྩོམ་ཚུལ་དངོས་དང་། དེ་ལྟར་བརྩམས་པའི་དགོས་པ་གཉིས། དང་པོ་ལ། གང་ལ་བརྟེན་ནས་རྩོམ་ཚུལ་དང་། དེ་ལྟར་བརྩམས་པའི་བསྟན་བཅོས་འདི་ཐུན་མོང་མ་ཡིན་པར་སྟོན་པ་གཉིས།
Enumeration Block 20:
གཉིས་པ་དགོས་པ་ལ། དངོས་དང་། དགོས་པ་དེ་ལྡན་གྱི་གཞུང་འདི་ཁོ་ན་འཛིན་པར་གདམས་པ་གཉིས།
Enumeration Block 21:
བཞི་པ་མཇུག་གི་དོན་ལ་སློབ་དཔོན་གང་གིས་མཛད་པ་དང་། ལོ་ཙཱ་བ་གང་གིས་བསྒྱུར་ཚུལ་གཉིས།
