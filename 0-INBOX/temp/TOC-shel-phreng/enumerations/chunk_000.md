Enumeration Block 1:
དབུ་མ་ལ་འཇུག་པ་འདི་འཆད་པ་ལ། མཚན་གྱི་དོན། འགྱུར་གྱི་ཕྱག ། གཞུང་གི་དོན། མཇུག་གི་དོན་དང་བཞི་ལས།
Enumeration Block 2:
གསུམ་པ་ལ། བསྟན་བཅོས་རྩོམ་པ་ལ་འཇུག་པའི་ཡན་ལག་མཆོད་པར་བརྗོད་པ། བརྩམ་བྱ་བསྟན་བཅོས་ཀྱི་ལུས་དངོས། བརྩམ་པ་མཐར་ཕྱིན་པའི་བྱ་བའོ། །དང་པོ་ལ། བྱང་སེམས་ཀྱི་རྒྱུ་གསུམ་སྤྱིར་བསྟན་པ་དང་། དེ་ལས་བྱེ་བྲག་ཏུ་སྙིང་རྗེ་ལ་བསྟོད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ། སྙིང་རྗེ་ཆེན་པོ་ལ་སོ་སོར་མ་ཕྱེ་བར་བསྟོད་པ་དང་། ཕྱེ་སྟེ་ཕྱག་འཚལ་བ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ། སེམས་ཅན་ལ་དམིགས་པའི་སྙིང་རྗེ་ལ་བསྟོད་པ་དང་། ཆོས་དང་དམིགས་པ་མེད་པའི་སྙིང་རྗེ་ལ་བསྟོད་པ་གཉིས།
Enumeration Block 5:
གཉིས་པ་བརྩམ་བྱ་བསྟན་བཅོས་ཀྱི་ལུས་དངོས་ལ། གནས་སྐབས་ཀྱི་ས་བཤད་པ་དང་། མཐར་ཐུག་གི་ས་བཤད་པ་གཉིས། དང་པོ་ལ། ས་བཅུ་སོ་སོར་བཤད་པ་དང་། ས་ཡི་ཡོན་ཏན་བཤད་པ་གཉིས། དང་པོ་ལ་རབ་དགའ་སོགས་ལྔ་བཤད་པ་དང་། ས་དྲུག་པ་མངོན་དུ་གྱུར་པ་བཤད་པ། རིང་དུ་སོང་བ་སོགས་བཞི་བཤད་པའོ། །
Enumeration Block 6:
དང་པོ་ལ་ས་དང་པོ་རབ་ཏུ་དགའ་བ་བཤད་པ། གཉིས་པ་དྲི་མ་མེད་པ། གསུམ་པ་འོད་བྱེད་པ། བཞི་པ་འོད་འཕྲོ་བ། ལྔ་པ་སྦྱང་དཀའ་བ་བཤད་པ་དང་ལྔ། དང་པོ་ལ། ས་དང་པོ་དངོས་བཤད་པ་དང་། ལེའུའི་སྐབས་བསྡུ་བ་གཉིས། དང་པོ་ལ། ཁྱད་གཞི་ས་ཡི་ངོ་བོ་མདོར་བསྟན། ཁྱད་ཆོས་ས་ཡི་ཡོན་ཏན་རྒྱས་པར་བཤད་པ། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུ་བ་དང་གསུམ།
Enumeration Block 7:
གཉིས་པ་ལ། རང་གི་རྒྱུད་མཛེས་པར་བྱེད་པའི་ཡོན་ཏན། གཞན་གྱི་རྒྱུད་ཟིལ་གྱིས་གནོན་པའི་ཡོན་ཏན། ས་དང་པོར་ལྷག་པའི་ཡོན་ཏན་བསྟན་པ་དང་གསུམ། དང་པོ་ལ་དོན་ལྡན་གྱི་མཚན་ཐོབ་པའི་ཡོན་ཏན། རིགས་སུ་སྐྱེ་བ་སོགས་བླང་བྱའི་ཁྱད་པར་ཐོབ་པའི་ཡོན་ཏན། ངན་སོང་སོགས་སྦྱང་བྱ་འགགས་པའི་ཡོན་ཏན་གསུམ།
Enumeration Block 8:
གཉིས་པ་ལ། རིགས་ཀྱི་ཡོན་ཏན། སྤངས་པའི་ཡོན་ཏན། རྟོགས་པའི་ཡོན་ཏན། ནུས་པའི་ཡོན་ཏན། གོང་དུ་འཕེལ་བའི་ཡོན་ཏན་ལྔ།
Enumeration Block 9:
གསུམ་པ་ལ་དངོས་དང་། དེ་དཔེས་བཤད་པ་གཉིས།
Enumeration Block 10:
གཉིས་པ་གཞན་ཟིལ་གྱིས་གནོན་ཚུལ་ལ། དངོས་དང་འཕྲོས་དོན་གཉིས།
Enumeration Block 11:
གསུམ་པ་ས་དང་པོར་ལྷག་པའི་ཡོན་ཏན་ལ། ས་འདིར་སྦྱིན་པའི་ཕར་ཕྱིན་ལྷག་ཚུལ། སྦྱིན་པའི་བསྔགས་པ། སྦྱིན་པའི་དབྱེ་བ་གསུམ།
Enumeration Block 12:
གཉིས་པ་ལ། སྦྱིན་པའི་བསྔགས་པ་དངོས་དང་། བསྔགས་པ་དེ་ལྡན་གྱི་སྦྱིན་པ་ལ་བྱང་སེམས་རྣམས་གུས་པའི་ཚུལ་གཉིས། དང་པོ་ལ། རྟེན་དམན་པའི་སྦྱིན་པ་ལ་བསྔགས་པ། བྱང་སེམས་རྣམས་ཀྱི་སྦྱིན་པ་ལ་བསྔགས་པ། དེ་ལྟར་བསྔགས་པའི་མཇུག་བསྡུ་བ་གསུམ། དང་པོ་ལ། རྟེན་དམན་པ་ལ་སྦྱིན་པ་དགོས་ཚུལ་དང་། སྦྱིན་པ་བྱིན་པའི་ཕན་ཡོན་གཉིས།
Enumeration Block 13:
གཉིས་པ་ལ་སྦྱིན་པས་འཁོར་བའི་བདེ་བ་ཐོབ་ཚུལ་དང་། སྦྱིན་པས་མྱང་འདས་ཀྱི་བདེ་བ་ཐོབ་ཚུལ་གཉིས།
Enumeration Block 14:
གཉིས་པ་བསྔགས་པ་དེ་ལྡན་གྱི་སྦྱིན་པ་ལ་བྱང་སེམས་རྣམས་གུས་ཚུལ་ལ། སྦྱིན་པ་ལ་ཅི་ཙམ་གུས་པའི་ཚུལ་དང་། དེ་ལྟར་གུས་ནས་སྦྱིན་པ་གཏོང་ཚུལ་གཉིས།
Enumeration Block 15:
གཉིས་པ་དྲི་མ་མེད་པ་བཤད་པ་ལ། དངོས་དང་། ལེའུའི་སྐབས་བསྡུ་བ་གཉིས། དང་པོ་ལ། ཁྱད་གཞི་སའི་ངེས་ཚིགས་དེའི་ཁྱད་པར་གྱི་ཆོས། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུ་བ་གསུམ།
Enumeration Block 16:
གཉིས་པ་ལ། ས་འདིར་ཚུལ་ཁྲིམས་ཀྱི་ཕར་ཕྱིན་ལྷག་ཅིང་དག་པར་བསྟན་པ། ཚུལ་ཁྲིམས་ཀྱི་བསྔགས་པ། ཚུལ་ཁྲིམས་ཕར་ཕྱིན་གྱི་དབྱེ་བ་གསུམ། དང་པོ་ལ་དངོས་དང་། ཚུལ་ཁྲིམས་དག་ཚུལ་བཤད་པ་གཉིས།
Enumeration Block 17:
གཉིས་པ་ཚུལ་ཁྲིམས་ཀྱི་བསྔགས་པ་ལ། བསྔགས་པ་དངོས་དང་། བསྔགས་པ་དེ་ལྡན་གྱི་ཚུལ་ཁྲིམས་ལ་བྱང་སེམས་རྣམས་གནས་ཚུལ་གཉིས། དང་པོ་ལ་རྟེན་དམན་པར་ཡང་ཚུལ་ཁྲིམས་དགོས་ཚུལ་དང་། ཡོན་ཏན་ཐམས་ཅད་ཀྱི་རྟེན་དུ་འགྱུར་ཚུལ་གཉིས། དང་པོ་ལ། ཚུལ་ཁྲིམས་དང་བྲལ་བའི་ཉེས་དམིགས་དང་། ལྡན་པའི་ཕན་ཡོན་གཉིས། དང་པོ་ལ། ཚུལ་ཁྲིམས་དང་བྲལ་ན་བདེ་འགྲོ་མི་ཐོབ་པའི་སྐྱོན་དང་། བདེ་འབྲས་ལན་གཅིག་ཏུ་ཟད་པའི་སྐྱོན་དང་། ངན་སོང་ལས་ཐར་དཀའ་བའི་སྐྱོན་དང་། སྐྱོན་དེ་རྣམས་བསལ་བའི་ཕྱིར་སྦྱིན་པའི་རྗེས་སུ་ཚུལ་ཁྲིམས་བསྟན་པའི་ཚུལ་བཞི།
Enumeration Block 18:
གསུམ་པ་ས་གསུམ་པ་འོད་བྱེད་པ་བཤད་པ་ལ། ཁྱད་གཞི་སའི་ངེས་ཚིག་བཤད་པ། ཁྱད་ཆོས་སའི་ཡོན་ཏན། སའི་ཡོན་ཏན་བརྗོད་པའི་མཇུག་བསྡུ་བ་གསུམ།
Enumeration Block 19:
གཉིས་པ་ཁྱད་ཆོས་ས་ཡི་ཡོན་ཏན་ལ། ས་འདིར་ལྷག་པ་བཟོད་པའི་ཕར་ཕྱིན་བཤད་པ་དང་། ས་འདིར་འབྱུང་བའི་ཡོན་ཏན་གཞན་བཤད་པ་གཉིས། དང་པོ་ལ། ས་འདིར་བཟོད་པ་ལྷག་ཚུལ་དང་། བཟོད་པ་སྒོམ་ཚུལ། བཟོད་པའི་དབྱེ་བ་གསུམ།
Enumeration Block 20:
གཉིས་པ་བཟོད་པ་སྒོམ་ཚུལ་ལ། དོན་དམ་པའི་སྒོ་ནས་བཟོད་པ་སྒོམ་ཚུལ་དང་། ཀུན་རྫོབ་ཀྱི་སྒོ་ནས་བཟོད་པ་སྒོམ་ཚུལ་གཉིས།
Enumeration Block 21:
གཉིས་པ་ལ། ཁོང་ཁྲོ་བའི་སྐྱོན་ལ་བསམ་སྟེ་བཟོད་པ་སྒོམ་ཚུལ་དང་། བཟོད་པའི་ཕན་ཡོན་ལ་བསམ་སྟེ་བཟོད་པ་སྒོམ་ཚུལ་དང་། ཐུན་མོང་དུ་མཇུག་བསྡུ་བ་གསུམ། དང་པོ་ལ། དོན་མེད་པས་ཁྲོ་བར་མི་རིགས་པར་བསམ་སྟེ་བཟོད་པ་བསྒོམ་པ། ཕན་བྱེད་གནོད་པར་བསྒྱུར་མི་རིགས་པར་བསམ་སྟེ་བཟོད་པ་བསྒོམ་པ། ཁོང་ཁྲོ་སྡིག་པ་ཤིན་ཏུ་སྟོབས་ཆེ་བར་བསམ་སྟེ་བཟོད་པ་བསྒོམ་པ། འདི་ཕྱིར་འབྱུང་བའི་སྐྱོན་དུ་མར་བསམ་སྟེ་བཟོད་པ་སྒོམ་ཚུལ་དང་བཞི།
Enumeration Block 22:
གསུམ་པ་མཇུག་བསྡུ་ལ། ཕར་ཕྱིན་སྔ་མ་གསུམ་ཐུན་མོང་དུ་མཇུག་བསྡུ་བ་དང་། བྱེ་བྲག་ས་འདིའི་མཇུག་བསྡུ་བ་གཉིས།
Enumeration Block 23:
བཞི་པ་འོད་འཕྲོ་བཤད་པ་ལ་གསུམ། ས་འདིར་བརྩོན་འགྲུས་ལྷག་པ། སའི་ངེས་ཚིག་སྤང་བའི་ཁྱད་པར་གསུམ།
Enumeration Block 24:
ལྔ་པ་སྦྱང་དཀའ་བ་བཤད་པ་ལ། ཁྱད་གཞི་སའི་ངེས་ཚིག་དང་། ཁྱད་ཆོས་སའི་ཡོན་ཏན་གཉིས།
Enumeration Block 25:
གཉིས་པ་ས་དྲུག་པ་མངོན་དུ་གྱུར་པ་བཤད་པ་ལ། ཡུལ་ཅན་སའི་ངོ་བོ་མདོར་བསྟན། ཡུལ་སྟོང་ཉིད་རྒྱས་པར་བཤད། སའི་ཡོན་ཏན་བརྗོད་པའི་མཇུག་བསྡུ་བ་གསུམ།
