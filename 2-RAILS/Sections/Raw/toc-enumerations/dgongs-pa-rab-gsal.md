འཆད་པ་ལ་བཞི། མཚན་གྱི་དོན། འགྱུར་གྱི་ཕྱག །གཞུང་གི་དོན། མཇུག་གི་དོན་ནོ། །
Enumeration Block 2:
རྩ་བ་ཤེས་རབ་ལ་འཇུག་པའི་ཚུལ་གཉིས་ཡོད་དེ། ཟབ་པ་དང་རྒྱ་ཆེ་བའི་སྒོ་ནས་སོ། །
Enumeration Block 3:
གསུམ་པ་ལ་བཞི། བསྟན་བཅོས་རྩོམ་པ་ལ་འཇུག་པའི་ཐབས་མཆོད་པར་བརྗོད་པ། བརྩམས་པའི་བསྟན་བཅོས་ཀྱི་ལུས་དངོས། བསྟན་བཅོས་ཇི་ལྟར་བརྩམས་པའི་ཚུལ། བསྟན་བཅོས་བརྩམས་པའི་དགེ་བ་བསྔོ་བའོ། །དང་པོ་ལ་གཉིས། སྙིང་རྗེ་ཆེན་པོ་ལ་སོ་སོར་མ་ཕྱེ་བར་བསྟོད་པ་དང༌། སྙིང་རྗེ་ཆེན་པོ་ལ་སོ་སོར་ཕྱེ་སྟེ་ཕྱག་འཚལ་བའོ། །
Enumeration Block 4:
འདི་ལ་གཉིས། སྙིང་རྗེ་བྱང་སེམས་ཀྱི་གཙོ་བོའི་རྒྱུར་བསྟན་པ་དང༌། བྱང་སེམས་ཀྱི་རྒྱུ་གཞན་གཉིས་ཀྱི་ཡང་རྩ་བར་བསྟན་པའོ། །
Enumeration Block 5:
དང་པོ་ལ་གསུམ། ཉན་རང་གཉིས་ཐུབ་དབང་ལས་སྐྱེས་ཚུལ་དང༌། སངས་རྒྱས་རྣམས་བྱང་སེམས་ལས་འཁྲུངས་ཚུལ་དང༌། བྱང་ཆུབ་སེམས་དཔའི་རྒྱུའི་གཙོ་བོ་གསུམ་བསྟན་པའོ། །
Enumeration Block 6:
བསྔགས་པ་མཛད་པའི་དགོས་པ་བཞི་ལས།
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། སེམས་ཅན་ལ་དམིགས་པའི་སྙིང་རྗེ་ལ་ཕྱག་འཚལ་བ་དང༌། ཆོས་དང་དམིགས་པ་མེད་པ་ལ་དམིགས་པའི་སྙིང་རྗེ་ལ་ཕྱག་འཚལ་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། རྒྱུའི་ས་དང༌། འབྲས་བུའི་སའོ། །དང་པོ་ལ་གསུམ། ལུགས་འདིའི་ལམ་ཉམས་སུ་ལེན་ཚུལ་སྤྱིར་བསྟན་པ་དང༌། བྱེ་བྲག་ཏུ་སོ་སྐྱེའི་སར་ཉམས་སུ་ལེན་ཚུལ་བཤད་པ་དང༌། བྱང་སེམས་འཕགས་པའི་སའི་རྣམ་གཞག་བསྟན་པའོ། །

Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། རྒྱུའི་ས་དང༌། འབྲས་བུའི་སའོ། །དང་པོ་ལ་གསུམ། ལུགས་འདིའི་ལམ་ཉམས་སུ་ལེན་ཚུལ་སྤྱིར་བསྟན་པ་དང༌། བྱེ་བྲག་ཏུ་སོ་སྐྱེའི་སར་ཉམས་སུ་ལེན་ཚུལ་བཤད་པ་དང༌། བྱང་སེམས་འཕགས་པའི་སའི་རྣམ་གཞག་བསྟན་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ། ས་བཅུའི་ཐུན་མོང་གི་རྣམ་གཞག །ས་སོ་སོའི་རྣམ་གཞག །ས་བཅུའི་ཡོན་ཏན་བསྟན་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། རབ་དགའ་སོགས་ས་ལྔ་བཤད་པ་དང༌། ས་དྲུག་པ་མངོན་དུ་གྱུར་པ་བཤད་པ་དང༌། རིང་དུ་སོང་བ་སོགས་ས་བཞི་བཤད་པའོ། །དང་པོ་ལ་ལྔ། ས་དང་པོ་རབ་ཏུ་དགའ་བ་དང༌། ས་གཉིས་པ་དྲི་མ་མེད་པ་དང༌། ས་གསུམ་པ་འོད་བྱེད་པ་དང༌། ས་བཞི་པ་འོད་འཕྲོ་བ་དང༌། ས་ལྔ་པ་སྦྱང་དཀའ་བ་བཤད་པའོ། །དང་པོ་ལ་གསུམ། ཁྱད་གཞི་སའི་ངོ་བོ་མདོར་བསྟན། ཁྱད་ཆོས་སའི་ཡོན་ཏན་རྒྱས་པར་བཤད། སའི་ཡོན་ཏན་བརྗོད་པའི་སྒོ་ནས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། རང་གི་རྒྱུད་མཛེས་པར་བྱེད་པའི་ཡོན་ཏན། གཞན་གྱི་རྒྱུད་ཟིལ་གྱིས་གནོན་པའི་ཡོན་ཏན། ས་དང་པོར་ལྷག་པའི་ཡོན་ཏན་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། ཡོན་ཏན་སོ་སོར་ཕྱེ་སྟེ་བཤད་པ་དང༌། ཡོན་ཏན་མདོར་བསྡུས་ཏེ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། དོན་ལྡན་གྱི་མཚན་འཐོབ་པའི་ཡོན་ཏན། རིགས་སུ་སྐྱེ་བ་སོགས་བཞིའི་ཡོན་ཏན། ས་གོང་མ་གནོན་པ་སོགས་གསུམ་གྱི་ཡོན་ཏན་ནོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། ས་འདིར་ཉན་རང་རྣམས་རིགས་ཀྱི་སྒོ་ནས་ཟིལ་གྱིས་གནོན་པ་དང༌། ས་བདུན་པར་ཉན་རང་གཉིས་བློའི་སྒོ་ནས་ཟིལ་གྱིས་གནོན་པ་དང༌། དེ་ལྟར་གསུངས་པས་གྲུབ་པའི་དོན་བཤད་པའོ། །
Enumeration Block 6:
གསུམ་པ་ལ་གསུམ། ས་བཅུ་པའི་མདོས་ཉན་རང་ལ་ཆོས་རང་བཞིན་མེད་པར་རྟོགས་པ་ཡོད་པར་བསྟན་པ་དང༌། དེ་སྒྲུབ་པའི་ཁུངས་བསྟན་པ་དང༌། དེ་ལྟར་བསྟན་པ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གཉིས། འགྲེལ་པ་མཛད་པའི་དགོངས་པ་གསལ་བར་བཤད་པ་དང༌། དེ་ཉིད་སྤྱོད་འཇུག་གི་ལུགས་སུའང་བསྟན་པའོ། །

Enumeration Block 1:
གསུམ་པ་ལ་གསུམ། ས་བཅུ་པའི་མདོས་ཉན་རང་ལ་ཆོས་རང་བཞིན་མེད་པར་རྟོགས་པ་ཡོད་པར་བསྟན་པ་དང༌། དེ་སྒྲུབ་པའི་ཁུངས་བསྟན་པ་དང༌། དེ་ལྟར་བསྟན་པ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གཉིས། འགྲེལ་པ་མཛད་པའི་དགོངས་པ་གསལ་བར་བཤད་པ་དང༌། དེ་ཉིད་སྤྱོད་འཇུག་གི་ལུགས་སུའང་བསྟན་པའོ། །
Enumeration Block 2:

Enumeration Block 3:

Enumeration Block 1:
གསུམ་པ་ལ་བཞི། ས་དང་པོ་ལ་གནས་པའི་སྦྱིན་པ་བཤད་པ། རྟེན་དམན་པ་རྣམས་ཀྱི་སྦྱིན་པ་བཤད་པ། བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སྦྱིན་པ་བཤད་པ། སྦྱིན་པའི་ཕར་ཕྱིན་གྱི་དབྱེ་བ་བསྟན་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སྦྱིན་པས་འཁོར་བའི་བདེ་བ་འཐོབ་པ་དང༌། སྦྱིན་པས་མྱང་འདས་ཀྱི་བདེ་བ་འཐོབ་པར་བསྟན་པའོ། །
Enumeration Block 3:

Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། ཆོས་ཀྱི་བདག་མེད་རིགས་པས་བསྒྲུབ་པ་དང༌། གང་ཟག་གི་བདག་མེད་རིགས་པས་བསྒྲུབ་པའོ། །དང་པོ་ལ་བཞི། མཐའ་བཞིའི་སྐྱེ་བ་བདེན་པ་གཉིས་ཀར་དགག་པ། དེ་ལྟར་བཀག་པ་ལ་རྩོད་པ་སྤང་བ། རྟེན་འབྱུང་གི་སྐྱེ་བ་ཉིད་ཀྱིས་མཐར་འཛིན་གྱི་ལོག་རྟོག་འགོག་ཚུལ། རིགས་པས་དཔྱད་པ་བྱས་པའི་འབྲས་བུ་ངོས་གཟུང་བའོ། །དང་པོ་ལ་གསུམ། རང་བཞིན་གྱིས་སྐྱེ་བ་མེད་པའི་དམ་བཅའ་བཞག་པ། དེ་རིགས་པས་སྒྲུབ་པའི་སྒྲུབ་བྱེད་བསྟན་པ། མཐའ་བཞིའི་སྐྱེ་བ་བཀག་པས་གྲུབ་པའི་
Enumeration Block 2:
གཉིས་པ་ལ་བཞི། བདག་སྐྱེ་དགག་པ། གཞན་སྐྱེ་དགག་པ། གཉིས་ཀ་ལས་སྐྱེ་བ་དགག་པ། རྒྱུ་མེད་པར་སྐྱེ་བ་དགག་པའོ། །དང་པོ་ལ་གཉིས། འགྲེལ་པ་མཛད་པའི་རིགས་པས་དགག་པ། རྩ་བ་ཤེས་རབ་ཀྱི་རིགས་པས་དགག་པའོ། །དང་པོ་ལ་གསུམ། དེ་ཁོ་ན་ཉིད་རྟོགས་པར་འདོད་པའི་གྲུབ་མཐའ་མཁན་གྱི་ལུགས་དགག་པ། གྲུབ་མཐས་བློ་མ་བསྒྱུར་བའི་ཐ་སྙད་དུ་ཡང་མེད་པར་བསྟན་པ། དེ་ལྟར་བཀག་པ་རྣམས་ཀྱི་དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། རང་དང་ངོ་བོ་གཅིག་པའི་རྒྱུ་ལས་སྐྱེ་བ་དགག་པ། རྒྱུ་དང་འབྲས་བུ་གཉིས་ངོ་བོ་གཅིག་པ་དགག་པའོ། །དང་པོ་ལ་གསུམ། ངོ་བོ་གཅིག་པའི་རྒྱུ་ལས་སྐྱེ་ན་དོན་མེད་དུ་ཐལ་བ་དང༌། ངོ་བོ་གཅིག་པ་ལས་སྐྱེ་ན་རིགས་པ་དང་འགལ་བ་དང༌། དེ་དག་གི་ཉེས་སྤོང་གི་ལན་དགག་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། ས་མྱུག་གཉིས་ལ་དབྱིབས་སོགས་ཐ་དད་མེད་པར་ཐལ་བས་དགག །དེའི་ཉེས་སྤོང་གི་ལན་དགག །གནས་སྐབས་གཉིས་ཀྱི་རེ་རེར་གཉིས་ཀ་འཛིན་མི་འཛིན་མཚུངས་པར་ཐལ་བས་དགག་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། ཕྱོགས་སྔ་མ་བརྗོད་པ་དང༌། ལུགས་དེ་དགག་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། གཞན་སྐྱེ་འདོད་པའི་ཕྱོགས་སྤྱིར་དགག་པ་དང༌། སེམས་ཙམ་པའི་ལུགས་བྱེ་བྲག་ཏུ་དགག་པའོ། །དང་པོ་ལ་ལྔ། གཞན་སྐྱེ་དགག་པ་དངོས། བཀག་པ་ལ་འཇིག་རྟེན་གྱི་གནོད་པ་སྤང་བ། དེ་ལྟར་བཀག་པའི་ཡོན་ཏན་བསྟན་པ། རང་བཞིན་གྱིས་སྐྱེ་བ་འགར་ཡང་མེད་པར་བསྟན་པ། བདེན་པ་གཉིས་ཆར་དུའང་རང་བཞིན་གྱིས་སྐྱེ་བ་བཀག་པའི་ཡོན་ཏན་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། གཞན་སྐྱེ་སྤྱིར་དགག་པ། གཞན་སྐྱེ་བྱེ་བྲག་ཏུ་དགག་པ། འབྲས་བུ་ལ་མུ་བཞིར་དཔྱད་ནས་གཞན་སྐྱེ་དགག་པའོ། །དང་པོ་ལ་གཉིས། ཧ་ཅང་ཐལ་བས་དགག །སྐྱོན་སྤོང་གི་ལན་དགག་པའོ། །དང་པོ་ལ་གཉིས། ཧ་ཅང་ཐལ་བ་དངོས་དང༌། དེ་དག་གི་མཐའ་དཔྱད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། གཞན་སྐྱེ་ལ་ཧ་ཅང་ཐལ་བ་འཇུག་པའི་རྒྱུ་མཚན། ཐལ་བ་ལས་བཟློག་པ་ཁས་ལེན་པ་ཡི་འགལ་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། སྐྱོན་སྤོང་གི་ལན། ལན་དེ་དགག་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། རྒྱུ་འབྲས་སྔ་ཕྱི་བ་ལ་གཞན་སྐྱེ་དགག་པ། རྒྱུ་འབྲས་དུས་མཉམ་པ་ལ་གཞན་སྐྱེ་དགག་པའོ། །དང་པོ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང༌། བཀག་པ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས། འཇིག་རྟེན་གྱི་གྲགས་པས་གཞན་སྐྱེ་ཁས་བླངས་ནས་འཇིག་རྟེན་གྱི་གནོད་པ་སྤང་བ། འཇིག་རྟེན་གྱི་ཐ་སྙད་དུ་ཡང་གཞན་སྐྱེ་མེད་པས་འཇིག་རྟེན་གྱི་གནོད་པ་སྤང་བའོ། །དང་པོ་ལ་གཉིས། འཇིག་རྟེན་གྱིས་གནོད་པའི་རྩོད་པ་དང༌། དེས་མི་གནོད་པའི་ལན་བསྟན་པའོ། །
Enumeration Block 10:
དེ་ལ་བདེན་པ་གཉིས་ཀྱི་རྣམ་དབྱེ་བསྟན་པ་སྔོན་དུ་འགྲོ་བ་དགོས་པ་ལ་ལྔ། བདེན་པ་གཉིས་ཀྱི་སྤྱིའི་རྣམ་གཞག །སྐབས་ཀྱི་དོན་ལ་སྦྱར་བ། བདེན་གཉིས་སོ་སོའི་ངོ་བོ་བཤད་པ། བཀག་པ་ལ་འཇིག་རྟེན་གྱིས་གནོད་པ་ལ་གནོད་བྱེད་བསྟན་པ། འཇིག་རྟེན་གྱིས་གནོད་པའི་གནོད་ཚུལ་བསྟན་པའོ། དང་པོ་ལ་བཞི། བདེན་གཉིས་སུ་དབྱེ་བས་ཆོས་རྣམས་ལ་ངོ་བོ་གཉིས་གཉིས་ཡོད་པར་བརྗོད་པ། བདེན་གཉིས་ཀྱི་རྣམ་གཞག་གཞན་བསྟན་པ། འཇིག་རྟེན་ལ་ལྟོས་ཏེ་ཀུན་རྫོབ་ཀྱི་དབྱེ་བ་བཤད་པ། ཞེན་ཡུལ་ལ་འཁྲུལ་བའི་ཞེན་ཡུལ་ཐ་སྙད་དུ་ཡང་མེད་པར་བསྟན་པའོ། །

Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། འཇིག་རྟེན་གྱི་གྲགས་པས་གཞན་སྐྱེ་ཁས་བླངས་ནས་འཇིག་རྟེན་གྱི་གནོད་པ་སྤང་བ། འཇིག་རྟེན་གྱི་ཐ་སྙད་དུ་ཡང་གཞན་སྐྱེ་མེད་པས་འཇིག་རྟེན་གྱི་གནོད་པ་སྤང་བའོ། །དང་པོ་ལ་གཉིས། འཇིག་རྟེན་གྱིས་གནོད་པའི་རྩོད་པ་དང༌། དེས་མི་གནོད་པའི་ལན་བསྟན་པའོ། །
Enumeration Block 2:
བདེན་པ་གཉིས་ཀྱི་རྣམ་དབྱེ་བསྟན་པ་སྔོན་དུ་འགྲོ་བ་དགོས་པ་ལ་ལྔ། བདེན་པ་གཉིས་ཀྱི་སྤྱིའི་རྣམ་གཞག །སྐབས་ཀྱི་དོན་ལ་སྦྱར་བ། བདེན་གཉིས་སོ་སོའི་ངོ་བོ་བཤད་པ། བཀག་པ་ལ་འཇིག་རྟེན་གྱིས་གནོད་པ་ལ་གནོད་བྱེད་བསྟན་པ། འཇིག་རྟེན་གྱིས་གནོད་པའི་གནོད་ཚུལ་བསྟན་པའོ། དང་པོ་ལ་བཞི། བདེན་གཉིས་སུ་དབྱེ་བས་ཆོས་རྣམས་ལ་ངོ་བོ་གཉིས་གཉིས་ཡོད་པར་བརྗོད་པ། བདེན་གཉིས་ཀྱི་རྣམ་གཞག་གཞན་བསྟན་པ། འཇིག་རྟེན་ལ་ལྟོས་ཏེ་ཀུན་རྫོབ་ཀྱི་དབྱེ་བ་བཤད་པ། ཞེན་ཡུལ་ལ་འཁྲུལ་བའི་ཞེན་ཡུལ་ཐ་སྙད་དུ་ཡང་མེད་པར་བསྟན་པའོ། །

Enumeration Block 2:

Enumeration Block 1:

Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། རྒྱུ་འབྲས་རང་བཞིན་གྱིས་གྲུབ་པ་འགོག་པ་ལ་སྐྱོན་མཚུངས་པའི་རྩོད་པ། རང་ལ་སྐྱོན་མི་མཚུངས་པའི་ལན་བསྟན་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི། རང་གི་ཕྱོགས་ལ་སུན་འབྱིན་དང་སྒྲུབ་པ་འཐད་ཚུལ། གཞན་གྱི་ཐལ་བ་མི་མཚུངས་པའི་རྒྱུ་མཚན་གསལ་བར་བཤད་པ། རང་བཞིན་མེད་པ་སྒྲུབ་ནུས་པ་བཞིན་དུ་གཞན་གྱིས་བཟློག་སྟེ་བསྒྲུབ་མི་ནུས་པ། འདིར་མ་བཤད་པའི་སུན་འབྱིན་ལྷག་མ་ཤེས་པར་བྱེད་ཚུལ་ལོ། །
Enumeration Block 4:

Enumeration Block 5:
